# 微缩铁路小镇 · Meadowbank

一个放在桌面上的 HO 比例微缩铁路沙盘。Three.js 实时渲染，全部几何体与贴图在运行时程序化生成，
不依赖任何图片资源、不需要后端。

打开页面即可看到完整沙盘与默认运行中的列车：一节 pannier-tank 机车牵引两节车厢，
沿闭合单线绕行，每两秒停靠一次车站，跨过河上的钢桁梁桥。

---

## 环境要求

- Node.js ≥ 20.19（Vite 7 的要求；本次验证使用 v24）
- 支持 WebGL2 的桌面浏览器（Chrome / Edge / Firefox / Safari 16+）

## 安装

```bash
npm install
```

## 启动开发服务器

```bash
npm run dev
```

默认端口 `5173`（见 `vite.config.js`）。若该端口已被占用：

```bash
npm run dev -- --port 5321 --strictPort
```

## 构建与预览

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览构建产物，默认端口 4173
```

## 操作说明

| 控件 | 作用 |
| --- | --- |
| 运行 / 暂停 | 启停列车。**暂停时列车行进与到站倒计时同时冻结**，恢复后从中断处继续 |
| 复位 | 恢复确定的初始机位、列车位置、速度（1.00×）与圈数计数 |
| 速度滑块 | 0.20× – 3.00×，实时生效 |
| 白天 / 傍晚 / 夜晚 | 三种光照预设，1.35 秒插值过渡；默认傍晚 |
| 环视 / 跟随列车 | 等距俯瞰全沙盘，或贴近列车的跟随机位 |
| 鼠标左键拖拽 | 旋转视角 |
| 滚轮 | 缩放（10 – 140） |
| 鼠标右键拖拽 | 平移 |

键盘：`空格` 运行/暂停 · `R` 复位 · `1` 白天 · `2` 傍晚 · `3` 夜晚 · `F` 跟随列车

窗口变窄时控制面板会自动折叠；双击面板也可手动折叠。

## 场景构成

- **展示底座**：29.2 × 22.2 × 1.45 的木质箱体，四周凸出边框压住场景板边缘，
  黄铜角码、内衬线、四只脚与铭牌（MEADOWBANK · HO 1:87）。箱体顶部是**开口**的：
  场景板嵌在边框围出的洞口里，因此河床下切到水位以下时水面仍然看得见，
  而不是被箱体的顶面挡住。场景板下方是渐隐的桌面，用于承接投影。
- **闭合铁路**：圆角矩形环线，长 59.64 场景单位，轨距 0.62，
  道砟床、枕木（199 根实例化，逐根色差）、连续长钢轨、里程标、车站高站台、4 架信号机。
- **车站**：站台雨棚、时钟、站名牌、售货亭，与站台边缘对齐。
- **河流与跨河结构**：小河自沙盘西缘偏南处进入，以约 38° 的斜交角穿过环线西侧的直线段，
  下游汇入磨坊池塘。铁路上以 **0.74 高的路桥面**过河——河床在桥下自然下切，
  桥位前后各 2.20 为水平桥面，再以 5.60 的余弦坡降回地面，桥两端即路基开始处。
  桥梁为双跨华伦式上承钢板桁梁，含桥台、翼墙、压项、分水尖桥墩与人行道；
  桥台与线路正交、与水流斜交，是铁路斜交口的常见做法。另有人行木桥在下游跨河。
- **小镇**：29 栋建筑（车站、市政厅带穹顶、教堂带尖塔、磨坊带水车、货棚、谷仓、
  联排住宅与农舍），按功能分区而非随机摆放；3 处广场、集市十字、喷泉、水塔、货物吊车。
- **道路**：7 条道路（主街、道口引道、集市环路、磨坊巷、塘边路、农舍车道、田间小径），
  以贴合地面的等高带宽带铺设并带路缘石，连接车站与主要建筑群，仅在指定点与铁路平交。
- **层次与细节**：18 处树丛（4 种树型，拒绝采样避开轨道/水面/道路/建筑）、7 段树篱、
  芦苇、栅栏、长椅、木桶、干草垛、小船、路牌等 25 件道具、6 根电报杆（带垂弧导线）、
  Semaphore 与远动信号、路灯 16 盏、人物 8 个作为比例参照。

## 实现要点

- **单一真值源**：`src/scene/layout.js` 用弧长参数化的闭合中心线（`Path2`）同时驱动
  钢轨扫掠、道砟、枕木、列车定位、地形压平与自检；`deckY(s)` 给出线路纵向高程，
  `trackFrame(s)` 给出切线/法线/上方向，因此轨道、桥梁、路基、地形永远一致。
- **列车运动**：每节车辆沿同一中心线**独立采样**，以耦合间距换算的弧长偏移定位；
  车体朝向由前后两台转向架切线的角平分线求出，转向架本身在世界空间独立旋转，
  因此过弯时各节车厢有自己的朝向与间距，而不是整列车绕中心刚体旋转。
- **地形与水系**：高度场 = 丘陵 + fBm 噪声，经建筑/广场/道路/线路走廊压平后，
  再被河流高斯谷地与池塘 SDF 下切；水面网格按 0.13 栅格扫描，
  顶点取 `max(地形, 水位)`，因此水陆交界既不漏水也不 z-fighting，
  同时以顶点色区分深水/浅水/干滩。
- **材质**：全部为程序化 CanvasTexture（草皮、田块、木纹、桥面木板、石材、砖、
  石板与瓦屋面、道砟、沥青/块石/卵石/碎石路面、水面波纹、立面图与自发光窗图、
  车厢车窗、站名牌、天空渐变），配合每个光照预设单独烘焙的 PMREM 环境贴图。
- **昼夜**：三套预设插值过渡；`registry.nightGlow` 统一驱动窗玻璃、路灯、机车头灯、
  信号机色片与车站时钟的自发光强度，`registry.nightPools` 驱动地面上的加法混合灯光池。
- **性能**：枕木、树木、树篱、芦苇、花园花坛使用 `InstancedMesh`；
  建筑/桥梁/栅栏按材质合并几何体；阴影贴图 2048 且正交范围收紧到沙盘；
  帧时间超过阈值时自动下调设备像素比。

## 目录结构

```
index.html
vite.config.js
src/
  main.js              渲染器、相机自动取景、OrbitControls、主循环、预设与视图切换
  ui.js                HUD 面板、状态读数、键盘快捷键
  style.css
  scene/
    layout.js          布局数学与自检报告（单一真值源）
    places.js          建筑/道路/树丛/道具等作者数据
    base.js            展示底座、桌面
    terrain.js         地形与水面
    track.js           轨道、站台、道口、桥梁、人行桥
    roads.js           道路与广场
    buildings.js       各类建筑的几何生成
    town.js            城镇装配：路灯、信号、树、道具、人物
    train.js           机车 + 两节车厢、转向架、烟雾、到站状态机
    lighting.js        三套光照预设与过渡
    world.js           场景组装与逐帧更新
  util/                数学、路径、几何、贴图工具
```

## 未验证 / 已知限制

- **帧率只在软件渲染环境下测得**：本次浏览器使用 `Microsoft Basic Render Driver`
  （无硬件 GPU 加速），531×553 视口、设备像素比 1 时约 41–44 fps，
  单帧约 85.6k 三角形、446 次 draw call；关闭阴影可升到约 52 fps。
  **未在真实 GPU 上测量**，预期硬件环境会显著高于此数值，但此处不做保证。
- 跟随机位在列车紧贴高大建筑时仍可能与屋檐短暂相交（已抬高至 3.5 的最低高度以缓解）。
- 场景为单线程程序化生成，首次加载需构建全部几何与贴图（开发模式下 `domComplete` 约 3.4 s，
  含 Vite 模块请求；生产构建会更快）。
- 未做多语言、未做移动端触摸适配（OrbitControls 本身可用，但 HUD 未针对触屏尺寸调整）。
- 水面为静态网格 + 贴图滚动，不做真实折射与反射。
