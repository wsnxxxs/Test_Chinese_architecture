# 云栖古刹 · 体素中式古建筑群（Voxel Chinese Temple）

用 **Three.js + Vite** 实现的 3D 体素风格中国古典寺院建筑群。整座寺院由约 180 万个体素程序化“堆”出来——
重檐庑殿顶的大殿、歇山顶的山门与天王殿、钟鼓楼、配殿、藏经阁、八角七层双塔、牌坊与石拱桥，
配以台地、铺装、水池、远山、云、鸟、行人，以及从黎明到月夜的连续光影。

页面打开即进入场景，默认镜头就能看到建筑群全貌，无需任何操作。

---

## 1. 运行方式

环境：Node.js ≥ 18（Vite 6），现代浏览器（Chrome / Edge / Firefox / Safari，需要 WebGL2）。

```bash
# 安装依赖
npm install

# 开发模式（热更新），默认 http://127.0.0.1:5173
npm run dev

# 生产构建 → dist/
npm run build

# 本地预览构建产物，默认 http://127.0.0.1:4173
npm run preview
```

> `dist/` 需要通过 HTTP 访问（`npm run preview` 或任意静态服务器），不能直接双击 `index.html`（ES Module 的跨域限制）。

### URL 参数（调试 / 截图用）

| 参数 | 说明 |
| --- | --- |
| `?t=0.715` | 初始时刻，0=午夜，0.25=日出，0.5=正午，0.75=日落 |
| `?view=axis` | 初始视角：`overview / axis / hall / gate / pagoda / top` |
| `?q=high` | 画质：`auto`（默认）/ `high` / `medium` / `low` / `lite` |
| `?hud=0` `?labels=0` | 隐藏界面 / 隐藏建筑标注 |
| `?slow=40` | 调试：每帧人为增加 40 ms 耗时，用来验证自适应画质会逐级降档 |

## 2. 操作说明

* **鼠标**：左键拖拽旋转 · 滚轮缩放（朝光标方向）· 右键拖拽平移；**触屏**：单指旋转、双指缩放/平移。
* **视角按钮（左下）/ 数字键 1-6**：全景 · 中轴 · 主殿 · 山门 · 宝塔 · 俯瞰，镜头平滑飞行。
* **时间（底部）**：黎明 · 午后 · 夕照（默认）· 暮色 · 月夜五个预设，或拖动滑块连续变化；
  “流转”（`C`）让昼夜自动循环，光影、天空、雾色、灯笼亮度随之变化。
* **标注（`L`）**：为每座建筑标出名称与屋顶形制，**点击标注可飞到该建筑**；标注带碰撞避让，主殿优先。
* **环游（`R`）**：自动绕场景旋转。**画质（`Q`）**：自动 / 高 / 中 / 低 / 极简。`H` 隐藏界面。

## 3. 场景内容与主次关系

沿中轴线（坐北朝南，自南向北）依次是：

| 层级 | 建筑 | 形制 / 细节 |
| --- | --- | --- |
| **主** | **大雄宝殿**（主殿） | **重檐庑殿顶**，皇家明黄琉璃瓦绿剪边；两层汉白玉须弥座台基 + 月台、御路踏跺、栏杆；周围廊、斗拱、鸱吻、垂脊走兽；殿内金身坐佛与莲座 |
| 次 | 山门 | 歇山顶，中央通道 + 金钉红门扇，门额匾牌，左右石狮 |
| 次 | 天王殿 | 歇山顶，穿堂式（中轴贯通），前廊、灯笼、匾额 |
| 次 | 钟楼 / 鼓楼 | 砖砌台座 + 拱形券洞，上层敞轩歇山顶；楼内悬铜钟、立大鼓 |
| 次 | 藏经阁 | 重檐歇山顶，楼阁式，内置经架 |
| 次 | 东、西宝塔 | 七层八角楼阁式塔，出檐翘角、红柱、亮灯窗，鎏金塔刹 |
| 辅 | 伽蓝殿 / 祖师殿 / 观音殿 / 药师殿（4 座配殿） | 两座歇山顶、两座悬山顶，对称分列主庭院 |
| 辅 | 东、西禅堂 | 硬山顶，位于大殿两侧院 |
| 辅 | 碑亭 ×2、八角亭 ×2、角楼 ×4 | 各式攒尖顶（四角 / 八角） |
| 辅 | 牌坊、放生池石拱桥、回廊（东西各一条）、月洞门、围墙 | 三间四柱牌坊；单孔拱桥；单坡回廊；圆形月洞门 |

层级通过**体量、高度、台基层数、屋顶等级与色彩**来表达：明黄琉璃重檐庑殿（最高）> 绿琉璃歇山 / 重檐 > 青灰瓦悬山、硬山。

### 空间布局

* 整体严格**中轴对称**（左右完全镜像），前后共四进院落，地面逐级抬升：
  放生池（外）→ 山门 → 钟鼓楼院 → 天王殿 → 配殿主庭院 → 月台大殿院 → 后园（藏经阁、双塔）。
  台地之间以挡土墙、栏杆、踏跺相连。
* **道路**：中轴御道（石板）贯穿牌坊、石桥、山门、天王殿、庭院、台阶、月台直达大殿；
  支路连接钟鼓楼、各配殿、禅堂、八角亭、双塔；环寺林荫道连接广场，两侧行道树。
* 院落间距按体素比例设计：主庭院宽约 165、纵深约 77 体素；中轴御道宽 9、支路宽 5、配殿之间留有 10 体素的通道，
  花圃与松树排布在道路之间，足以容纳道路、庭院、花圃和行人（行人约 5 体素高，用来直观感受尺度）。

### 中式建筑语汇

* **屋顶**：歇山 / 庑殿 / 攒尖（方、八角）/ 悬山 / 硬山 / 重檐 / 单坡；曲面“举折”、檐口起翘、翼角飞翘（翘角）、
  瓦垄条纹、正脊 + 鸱吻、垂脊 + 走兽、山花、檐下椽头彩画、风铃。
* **结构**：朱红立柱 + 柱础、额枋、两跳斗拱（蓝 / 绿 / 金彩绘）、隔扇门、棂格窗、台基、踏跺、御路、望柱栏杆。
* **色彩**：红墙、琉璃瓦（黄 / 绿 / 蓝）、青瓦、木色、汉白玉、青砖。
* **细节**：宫灯（夜间自发光 + 光晕）、石狮、铜香炉（升起青烟）、石灯、匾额、钟、鼓、佛像、太湖石、荷花与锦鲤。

### 环境与光影

* 地面：铺装（方砖 / 御路石板 / 广场大石板）、草地（噪声分色 + 野花）、碎石路、花圃、农田、水池荷叶；
  建筑与地面通过台基、散水、花圃镶边、护坡自然衔接。
* 光源：一个带阴影的主光（太阳 / 月亮）+ 半球环境光 + 补光；黎明 / 午后 / 夕照 / 暮色 / 月夜多种色调，
  夕照与暮色时灯笼、窗户、宝塔亮起，泛光（Bloom）呈现氛围；黎明与黄昏带有贴地的晨雾 / 暮霭（随高度衰减的雾），
  夜里出现星空、孔明灯与萤火虫。
* 远景：两圈粗体素山脉（4 与 16 体素单位，逐层偏冷的大气透视雾）+ 体素云 + 农田 / 林地色块，与精细地形无缝衔接。

## 4. 技术实现要点

```
src/
├─ main.js                 渲染器 / 后处理 / 主循环 / 自适应画质 / 镜头动画
├─ ui.js                   HUD：时间预设、视角、开关、快捷键
├─ voxel/                  体素引擎
│  ├─ grid.js              稠密体素网格 + Brush（平移 + 90° 旋转的局部坐标画笔，可 ASCII 建模）
│  ├─ mesher.js            分块面剔除网格化 + 顶点环境光遮蔽（AO）+ 逐体素颜色抖动
│  ├─ palette.js           115 种材质：颜色、抖动、自发光、光泽
│  └─ rng.js               哈希 / 值噪声
├─ world/                  程序化建造
│  ├─ roofs.js             高度场屋顶生成器（举折曲线 + 檐口翘角 + 瓦垄 + 脊饰）
│  ├─ parts.js             台基、踏跺、栏杆、斗拱、门窗图案、灯笼 ...
│  ├─ hall.js / doubleEave.js / mainHall.js / buildings.js / pagoda.js / structures.js
│  ├─ terrain.js / compound.js / far.js / trees.js / props.js
│  └─ generate.js          组装整座寺院
└─ scene/                  场景与氛围
   ├─ timeOfDay.js         关键帧昼夜系统（太阳 / 月亮、天空、雾、灯光、阴影视锥自适应）
   ├─ sky.js water.js clouds.js birds.js people.js particles.js labels.js views.js materials.js
```

* **体素渲染**：世界是一个 256×112×400 的 `Uint8Array`。网格化时只输出与空气相邻的面（面剔除），
  并按 32³ 分块；每个顶点烘焙 0fps 式 AO（并根据 AO 翻转四边形对角线）。
  一个共享 `MeshStandardMaterial`（通过 `onBeforeCompile` 加入 `glow` 自发光与 `gloss` 釉面光泽两个顶点通道）。
* **屋顶**：把屋顶看成“到檐口水平距离 ρ”的高度场 `y(ρ)`（凹曲线 + 檐口翘起 + 角点抬升），
  再栅格化成防漏的体素壳；同一套代码通过“边（半平面）集合”表达矩形、八边形、歇山（山面只对檐口的一部分生效）、悬山等。
* **阴影**：太阳阴影贴图（PCF，4096²）**只在光照变化时重绘**，平时每帧只有一次主渲染，因此可以放心提高阴影质量。
* **性能策略**：分块视锥裁剪；场景全静态几何；点精灵 / 实例化动画（烟、花瓣、光晕、鸟、行人、锦鲤）全部走 GPU 或极少量 CPU；
  自动画质：帧率低于 32 fps 时先降渲染分辨率，再逐级降低预设（高 → 中 → 低 → 极简），软件渲染器（SwiftShader）直接从“极简”起步。

## 5. 运行结果（实测）

* `npm install`、`npm run dev`、`npm run build`、`npm run preview` 均已实际运行通过（构建产物 ≈ 0.9 MB，gzip ≈ 240 KB）。
* 在 Windows 11 + Chrome（内置浏览器面板，NVIDIA RTX 5070 Ti，DPR 1，约 880×495 ~ 2254×1274 之间多种窗口尺寸）实测：
  * 首屏就绪（生成 + 网格化 + 上传）≈ 0.7 – 1.5 s；世界生成 ≈ 100 ms，网格化 ≈ 300 ms；
  * 实体体素 ≈ 1.8 M，可见面 ≈ 47 万（精细区）+ 23 万（远景）→ 每帧 ≈ 1.2 M 三角形、≈ 260 次 draw call；JS 堆 ≈ 110 MB；
  * 旋转 / 缩放 / 切换时段时帧率保持在显示器刷新率上限（≈ 180 fps），无卡顿。
* 已验证：五个时段的光影（黎明 / 午后 / 夕照 / 暮色 / 月夜）、六个预设视角、标注避让与点击飞行、时间滑块与昼夜流转、
  画质切换（含 `lite`）、竖屏 / 手机尺寸（375×812）布局与专用竖屏全景镜头。
* 说明：以上帧率来自高端独显；在低端设备上，自动画质会降低分辨率 / 预设以维持 ≥ 30 fps（该策略本身已实现并实测可切换，但我没有条件在真实低端硬件上做长时间压测）。
