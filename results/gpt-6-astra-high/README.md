# 方寸之间 · 云栖古寺

一个使用 Three.js 和 Vite 构建的中国古典体素建筑群。无需后端，打开页面即可看到完整场景。所有建筑、屋瓦、树木及环境细节均由代码生成，无需外部模型或图片。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端输出的本地地址：http://127.0.0.1:5186 。若端口被占用，可用 `npm run dev -- --port 5187` 指定其他端口。

```bash
npm run build
npm run preview
```

`build` 生成 `dist/`，可部署在静态网站服务上；`preview` 默认使用 4173 端口。浏览器需支持 WebGL 2。

## 场景

- 11 座建筑：大雄宝殿、藏经阁、四座配殿、山门、钟楼、鼓楼、东西五层宝塔。
- 中轴对称布局、连通道路、两进院落、双水庭、院墙与绿化。
- 体素飞檐、重檐屋顶、攒尖顶、斗拱、立柱、石阶、栏杆、格栅门窗、匾额、灯笼、石狮与香炉。
- 晨光和暮色两种光照，可自由旋转、缩放、自动环绕、复位视角及导出 PNG。
- 建筑图鉴可将镜头平滑移动至对应建筑。
- 桌面鼠标拖动旋转、滚轮缩放；触屏单指旋转、双指缩放。

本作是古典建筑意象的艺术化微缩创作，不是具体古建的测绘复原。界面使用可选 Google Fonts 中文衬线字体；离线时自动使用系统字体，不影响三维场景。

## 文件

```text
index.html       页面结构与可访问性标签
src/main.js      渲染、相机、光照、交互和性能统计
src/scene.js     程序化体素建筑与环境
src/style.css    页面样式和响应式布局
vite.config.js   本地端口、相对资源路径与 Three.js 独立打包
```

## 渲染策略

主体体素按材质合并为三个 `InstancedMesh`；匾额为小型 CanvasTexture。共用立方体几何，静态阴影仅在初次渲染和光照变化时更新，限制设备像素比并在低帧率时自动降低分辨率。页面底部显示实测 FPS，悬停可查看体素数量与绘制调用数。帧率取决于显卡、窗口尺寸与浏览器环境。

## 实际验证

2026-09-25 在本机浏览器完成检查：

- `npm run build` 成功，生产构建无警告；`npm run preview -- --port 4186 --strictPort` 正常显示场景。

- 13,268 个体素，常规画面 11 次绘制调用；桌面静态预览约 175–180 FPS，自动环绕时观察到约 156 FPS。此为当前机器测量，并非对所有设备的保证。
- 验证晨昏切换、图鉴定位、拖动旋转、复位、自动环绕、说明弹窗；图片导出已在下载目录实际生成 PNG 文件。
- 浏览器未记录警告或错误。
