# 暮光微缩铁路镇

一个使用 Three.js 制作的桌面微缩铁路小镇。场景包含带厚木边框的沙盘底座、闭合铁轨、跨河桥、车站、街道、建筑、植被和昼夜灯光。默认打开为傍晚，列车会由车头与两节车厢分别沿同一条闭合曲线运行，并会在 Pine Ridge 车站停留约两秒。

## 安装与启动

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

终端会显示本地访问地址。生产构建：

```bash
npm run build
npm run preview
```

## 使用方式

- 拖拽画面旋转视角，滚轮缩放。
- 使用右下角面板暂停/继续列车、调整行驶速度或复位场景。
- 切换至夜晚后，车站、路灯、建筑与列车窗户会点亮。
- 复位会恢复初始机位、列车位置、默认速度和运行状态；昼夜模式保持当前选择。

## 实现说明

- `src/main.js`：Three.js 场景、轨道样条、独立车厢跟随、站停状态机、昼夜切换和控件逻辑。
- `src/style.css`：覆盖在沙盘上的控制界面及昼夜主题样式。
- 未使用外部贴图或模型；建筑、桥梁、树木和列车均由基础几何体组合生成，以保留手工模型般的微缩质感。
