# PRISM-68 · 棱镜系列机械键盘 — 交互式产品展示与配置页

一个原创机械键盘（PRISM-68，65% 紧凑布局 / 68 键）的 3D 产品展示与在线配置页面。
3D 模型由 **Three.js** 程序化生成，配置界面为常规 HTML/CSS/JS，无需后端。

## 快速开始

```bash
npm install      # 安装依赖（three + vite）
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览构建产物
```

要求 Node.js 18+。页面打开即呈现完整键盘与默认配置（曜石黑外壳 + 晨雾白键帽）。

## 功能一览

- **3D 展示**：68 枚独立键帽（字母区、数字行、方向键，含 2u Backspace、2.25u Enter/Shift、6.25u 空格等不同宽度），键帽带高度差、缝隙与 Canvas 绘制字符；键帽 / 定位板 / 底壳三层结构清晰可辨，底壳带厚度、侧边装饰条与打字倾角。
- **视角操作**：拖动旋转、滚轮缩放（OrbitControls，带阻尼），「视角复位」平滑回到初始展示角度。
- **配色配置**：3 种外壳配色 × 3 种键帽主题任意组合，3D 预览、色卡选中态与配置摘要实时同步。
- **拆解 / 组装**：键帽、定位板、底壳三层沿垂直方向平滑展开 / 复原（smoothstep 缓动 + 键帽梯度错层）；动画基于进度值插值，快速反复点击也会收敛到正确位置。
- **试打体验**：开启后按下物理键盘 A–Z / 空格（及其他映射键），对应键帽下压回弹并播放合成的按键音（WebAudio）；触屏 / 鼠标可直接点击 3D 键帽点按。输入框、文本域获得焦点时不劫持按键。
- **本地保存**：配色变更自动写入 `localStorage`（键名 `prism68.config.v1`），刷新后恢复；「恢复默认」仅移除该键并重置为本页默认配置，不影响其他数据。

## 技术结构

```
prism-68/
├── index.html        # 页面结构：3D 视口 + 配置面板
├── src/
│   ├── main.js       # 场景/灯光/相机、交互事件、状态与持久化、渲染循环
│   ├── keyboard.js   # 键盘三层模型构建、字符贴图、主题应用、按压动画
│   ├── layout.js     # 68 键布局数据、外壳配色与键帽主题定义
│   └── style.css     # 界面样式
└── vite.config.js
```

- 键帽字符：每键一张 CanvasTexture，主题切换时仅重绘文字颜色。
- 拆解动画：单一 `explodeProgress` 进度值驱动三层位移，天然支持中途反向。
- 按键回弹：每键独立的按压值向目标值阻尼插值，与拆解位移叠加计算。
