# FORMA 68 配置展示页

FORMA 68 是一款原创机械键盘的交互式产品展示与配置页面。页面使用 React 和 Vite，Three.js 负责键盘 3D 模型；配置与操作界面由普通 HTML/CSS 实现。

## 本地启动

需要 Node.js 20.19+ 或 22.12+，以及 npm。

```sh
npm install
npm run dev
```

打开 Vite 输出的本地地址即可使用。创建生产构建并本地预览：

```sh
npm run build
npm run preview
```

## 页面操作

- 在三种外壳颜色和三种键帽主题中自由组合，模型与配置摘要会同步更新。
- 拖动模型可旋转，滚动可缩放；点击“复位视角”可回到初始角度与比例。
- 点击“拆解 / 组装”可平滑展开或复原键帽、定位板和底壳。
- 开启“键盘体验”后按 A–Z 或空格，可体验键帽下压与回弹；触屏也可直接点击模型中的键帽。文本输入等可编辑控件保留正常键盘行为。
- “保存我的配置”会将外壳和键帽选择保存在当前浏览器；刷新后会恢复。 “恢复默认”只删除本页面的 `forma68.saved-configuration.v1` 配置项。

模型采用紧凑 ANSI 风格的五行 68 键布局，不对应具体键盘品牌。
