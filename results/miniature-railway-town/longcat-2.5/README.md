# 桌面微缩铁路小镇

一个基于 Three.js 的桌面微缩铁路小镇沙盘。闭合铁路环绕小镇，一列火车（车头 + 两节车厢）沿轨道连续运行，跨河而过，到站自动停车。木底座、草地、河流、建筑、树木、路灯等构成手工模型般的质感。

## 安装

```bash
npm install
```

## 启动

```bash
npm run dev
```

打开终端提示的地址（默认 http://127.0.0.1:5173 ）即可看到完整沙盘和运行中的列车。

## 构建

```bash
npm run build
```

构建产物在 `dist/` 目录，可直接用任意静态服务器打开（如 `npx vite preview`）。

## 操作

| 操作 | 说明 |
|------|------|
| 拖动鼠标 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖动 | 平移 |
| 暂停 / 运行 | 暂停列车与到站计时 |
| 速度滑块 | 0.25x – 3x |
| 复位 | 恢复初始机位、列车位置与速度 |
| 白天 / 傍晚 / 夜晚 | 切换光照；夜晚车站、路灯、窗户与车灯发光 |

## 技术说明

- **Three.js** 核心 3D，原生 ES Modules + Vite 构建，无后端。
- 轨道为闭合 `CatmullRomCurve3`，车厢按弧长参数独立采样曲线定位，转弯时保持合理间距与朝向。
- 列车到站检测：车头经过车站中心弧长参数时触发 2 秒停车。
- 跨河处设铁路桥（桥墩立于河中），另有步行桥连接河对岸。
- 场景约 300 个网格，轨枕使用 `InstancedMesh`，单张 2048 阴影贴图。
