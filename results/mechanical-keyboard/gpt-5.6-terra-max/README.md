# AERIS 65 Keyboard Showcase

一个使用 Three.js 构建的原创机械键盘交互式展示与本地配置页面。

## 安装与启动

```bash
npm install
npm run dev
```

终端会输出本地访问地址。生产构建可使用：

```bash
npm run build
npm run preview
```

## 使用方式

- 在右侧选择三种外壳颜色与三种键帽主题，3D 预览和配置摘要会同步更新。
- 在预览区域拖动旋转、使用滚轮缩放，或使用底部的视角按钮；中间按钮会恢复默认视角。
- 点击“拆解结构”可在键帽、定位板和底壳三层之间切换，连续点击也会平滑过渡到最新状态。
- 点击任意 3D 键帽，或在未聚焦输入框时按 A–Z / 空格键，可以体验键帽下压和回弹。聚焦“配置名称”输入框后会保留正常输入行为。
- 点击“保存配置”会写入浏览器本地存储；刷新页面后会恢复。恢复默认仅移除本页使用的本地存储项。

## 技术说明

- 原生 HTML / CSS 承担所有产品文案、配置控件和配置摘要。
- Three.js 仅渲染键盘模型：独立的键帽、定位板、开关、底壳与灯效层，支持 OrbitControls 旋转与缩放。
