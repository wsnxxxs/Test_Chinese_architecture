# DENZA Z · Racing Studio

GPT-6 Astra Pro 生成的腾势 Z 2026 款 Racing 赛道版程序化三维外观展示。页面使用 Three.js 和原生 HTML/CSS/JavaScript，车辆、材质、灯光与影棚均在运行时生成，不使用现成汽车模型或外部网络资源。

## 构建

需要 Node.js 20+。在仓库根目录运行：

```bash
npm install
npm run build --workspace=denza-z-racing-studio
```

构建会检查源码语法，并生成包含离线资源和单文件版本的 `dist/`。

## 操作

- 鼠标或单指拖动旋转，滚轮或双指缩放；可切换正前、正侧、前后 3/4 和车尾视角。
- 可切换车身颜色、车灯、尺寸标注、明暗影棚与自动环绕，并导出当前三维画布。
- 正前、正侧和车尾使用正交投影，前后 3/4 使用透视投影。
