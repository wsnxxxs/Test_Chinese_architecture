# LOOM 68 · Keyboard Studio

原创机械键盘的交互式产品展示与配置页面。使用 Vite、原生 JavaScript 和 Three.js，无需后端。配置按钮、输入框、摘要和提示均使用正常 HTML/CSS；Canvas 只用于三维产品渲染。

## 安装与启动

需要 Node.js **20.19+ 或 22.12+**，推荐 Node.js 24 LTS。

```bash
npm install
npm run dev
```

打开终端输出的本地地址（默认为 `http://127.0.0.1:42868`；端口被占用时会自动选择下一个可用端口）。

```bash
npm run build
npm run preview
```

生产文件生成在 `dist/`，生产预览默认地址为 `http://127.0.0.1:42869`。将此目录部署到静态网站服务器即可。字体随项目打包，运行时无需调用外部字体、模型或图片服务。

## 使用方式

- **搭配**：三款铝壳配色 × 三套键帽主题，共九种组合。材质平滑切换，右侧摘要同步更新。
- **观察**：拖动模型旋转，鼠标滚轮或触屏双指缩放；也可使用 `−`、`+`、俯视与复位按钮。
- **拆解**：点击“拆解键盘”，键帽、定位板与底壳平滑展开；再次点击组装。动画中可随时切换方向。
- **体验**：打开“键盘体验”，按实体键盘 A–Z、空格或方向键。按住时键帽下压，松开回弹；鼠标或触屏点击任意键帽也可试敲。拖动旋转不会误触敲击。
- **声音**：体验开启后，可点击旁边的声音图标开启合成按键音，默认静音。
- **输入**：配置名称输入框正常接收输入；体验模式不会拦截输入框、文本域、选择框或可编辑内容，也不拦截系统组合快捷键。
- **保存**：为配置命名（可选），点击“保存我的配置”。配色、主题与名称保存到当前浏览器，刷新后自动恢复。修改配置后再次保存即可覆盖。
- **恢复默认**：恢复“苔绿 × 抹茶拿铁”，只删除 `loom68:configuration:v1` 这一项，保留其他网站或页面的本地数据。视角与拆解状态同时复位。

## 模型与实现

- 68 枚独立键帽，五行 65% 紧凑布局，完整数字行、字母区与方向键。
- 6.25u 空格、2.25u 回车、2.25u / 1.75u Shift 及其他不同宽度功能键。
- 程序化生成的圆角、收口键裙、微凹键顶与高分辨率字符贴图。
- 6° 倾角的空腔铝壳、底板、脚垫、USB-C 接口、指示灯与前侧标识。
- 开有 68 个轴孔的铝合金定位板、轴座、十字轴芯、长键稳定结构及底壳中的 PCB / 缓冲层。
- OrbitControls 视角操作、正交产品摄影视角、环境照明与软阴影。
- 拆解动画用单一进度计算每层绝对位置；连续点击不会累积位移。按键行程独立计算，可同时按多键；窗口失去焦点时释放按键。

## 文件结构

```text
src/
  main.js       页面、配置状态、输入事件、保存与声音
  keyboard.js   三维模型、材质、视角、拆解与键帽动画
  config.js     配色、默认状态、本地存储与按键布局
  icons.js      SVG 界面图标
  style.css     页面与响应式样式
public/
  favicon.svg   原创品牌图标
```

## 环境说明

三维预览需要支持 WebGL 2 的现代浏览器和硬件加速。不支持时会显示说明，配置和保存仍可使用。按键声音由 Web Audio 合成，是概念展示效果；本项目不包含实物商品销售或订单系统。

- 配色与名称保存后刷新，摘要、选项及名称均恢复；恢复默认后再次刷新，回到默认配置与未保存状态。

- 在俯视模型中点击 A 和空格，反馈对应正确；拖动模型旋转后，敲击计数不增加。操作了放大、缩小、俯视与视角复位按钮。
