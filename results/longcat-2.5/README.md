# Voxel 中式古建筑群 · 晨光

一个纯前端（Three.js + Vite）的 **3D 体素风格中国古典建筑群** 场景。
页面打开即进入场景：中轴对称的寺院建筑群在晨光中缓慢旋转，无需任何操作即可看到全貌。

## 运行方式

```bash
# 安装依赖（Node.js 20.19+ 或 22.12+）
npm install

# 开发模式（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build

# 本地预览构建产物
npm run preview
```

## 场景内容

**建筑群（10 栋，中轴对称，南→北）**

| 建筑 | 形制 | 说明 |
| --- | --- | --- |
| 牌坊 | 四柱三间三楼 | 金色琉璃小顶，入口标志 |
| 山门 | 单檐歇山顶 | 中央三门洞，青琉璃瓦 |
| 钟楼 / 鼓楼 | 重檐歇山顶 | 方形楼阁，鎏金顶尖 |
| 配殿 ×2 | 单檐歇山顶 | 分列第二进庭院东西，面向中轴 |
| 碑亭 ×2 | 攒尖顶 | 蓝琉璃瓦（祈年殿色系），内置石碑 |
| 主殿 | 重檐庑殿顶 | 三层汉白玉台基、黄琉璃瓦、斗拱、隔扇门 |
| 宝塔 | 五层楼阁式 | 青灰瓦、塔刹鎏金，位于中轴北端 |

**中式细节**：飞檐翘角（檐角起翘 + 鎏金）、戗脊 / 鸱吻 / 悬鱼、斗拱十字拱、
红墙立柱、槛窗窗棂、隔扇门金钉、台基台阶、石狮子、灯笼杆、香炉、
放生池、花坛、围墙。

**环境与光影**：晨光低角度暖阳（2048 阴影贴图）+ 冷色补光 + 半球光；
晨空渐变天穹（Shader）+ 日轮光晕；体素云缓慢漂移；晨尘微粒；
中轴御道 / 东西甬路 / 庭院铺装；雾效纵深。

## 性能

- 全部体素（约 1.5 万个）编译为 **1 个 InstancedMesh**（另 3 个自发光组），
  整个场景仅约 10 个 draw call，另限制阴影贴图尺寸与像素比。
- 左下角 HUD 实时显示 FPS 与体素统计。

## 操作

- 左键拖动：旋转视角；滚轮：缩放；右键拖动：平移
- 页面加载后自动缓慢环绕（交互时暂停，静置 5 秒恢复）
- 按 `H` 隐藏 / 显示界面

## 技术栈

- [Three.js](https://threejs.org/)（InstancedMesh、PCFSoft 阴影、ACES 色调映射、自定义天空 Shader）
- [Vite](https://vitejs.dev/) 构建
- 无后端、无其他运行时依赖；确定性随机种子，每次生成的场景一致

## 目录结构

```
voxel-chinese-temple/
├── index.html          # 页面入口 + HUD
├── package.json
├── vite.config.js
└── src/
    ├── main.js         # 场景 / 光照 / 天空 / 动画循环 / HUD
    ├── voxel.js        # 体素收集器 → InstancedMesh 编译（性能核心）
    ├── arch.js         # 中式建筑生成器（屋顶/斗拱/门窗/各建筑）
    ├── environment.js  # 铺装道路 / 围墙 / 树木 / 石狮 / 灯笼 / 水池
    ├── palette.js      # 中式色彩体系 + 颜色工具
    ├── rng.js          # 确定性伪随机
    └── style.css
```
