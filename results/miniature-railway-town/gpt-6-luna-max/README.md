# 河湾小镇 · 微缩铁路沙盘

一个使用 Three.js 和 Vite 制作的桌面微缩铁路小镇。场景中的底座、地形、房屋、桥梁、道路、植被和列车均由程序化几何与材质构成，无需后端或外部模型文件。

## 安装与启动

需要 Node.js 20.19 或更新版本，以及 npm。

```bash
npm install
npm run dev
```

在终端显示的本地地址打开页面，默认会看到傍晚场景和正在行驶的列车。生产构建：

```bash
npm run build
```

构建结果输出到 `dist/`。如需本地查看生产构建，可运行 `npm run preview`。

## 操作

- 拖动场景可旋转视角，滚轮可缩放；按住空格也可暂停或继续列车，按 `N` 切换昼夜。
- 底部按钮控制运行与暂停，速度滑杆调整速度，“复位”会恢复初始机位、列车位置、速度和傍晚灯光。
- “点亮夜景”会打开车站、路灯和车窗灯光。列车每次到达河湾站停靠约两秒；暂停时列车和停站倒计时都会冻结。

## 项目结构

- `src/main.js`：Three.js 场景、微缩模型、闭合轨道、列车运动与交互。
- `src/style.css`：页面布局、控制面板和响应式样式。
- `index.html`：应用入口与界面结构。
