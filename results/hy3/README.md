# 体素中国古典建筑群 · Voxel Temple

基于 **Three.js + Vite** 的 3D 体素（Minecraft 风格）中国古典建筑群场景。
打开浏览器即可俯瞰全貌，支持自由旋转、缩放、平移，镜头默认缓慢自动巡览。

## 场景构成（中轴对称院落布局）

| 建筑 | 位置 | 形制 / 说明 |
| --- | --- | --- |
| 山门 | 前端入口 (0, -30) | 歇山顶、青瓦、红墙，檐下灯笼 + 门前石狮 |
| 主殿 | 中轴核心 (0, 16) | **体量最大**，庑殿顶、琉璃黄瓦，高台基 + 前台阶 |
| 配殿（左/右） | 主殿前两侧 (±24, 4) | 对称分布，歇山顶、青瓦 |
| 宝塔 | 左侧 (-34, -10) | 六层攒尖顶，逐层收分，琉璃黄瓦 + 宝顶 |
| 钟楼 | 右侧 ( 34, -10) | 下层开敞（立柱栏杆）+ 上层歇山顶 |

道路动线：**山门 → 中央庭院铺装 → 主殿**，由石材铺装体素连成；并延伸支路至配殿与塔楼。
建筑细节涵盖：飞檐翘角、斗拱意象（角柱 + 檐口收分）、立柱、台阶、门窗格、灯笼、石狮、脊饰与宝顶。
环境含草地 + 石质铺装、黄昏方向光与阴影、雾气与暖色点光，呈现晨昏氛围与光影层次。

## 运行方式

需要 Node.js 18+（已用 Node 22 验证）。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（自动打开浏览器）
npm run dev

# 3. 或构建为静态文件后用 preview 预览
npm run build
npm run preview
```

打开 `http://localhost:5173`（dev 默认端口）即可观看。
`npm run build` 产物位于 `dist/`，可部署到任意静态托管。

## 性能说明

- 所有同色体素按颜色分组，使用 `InstancedMesh` 渲染（约 12 个 draw call），
  体素总数约 1.5–2.5 万，**普通 GPU 即可稳定 ≥30fps**（集成显卡亦流畅）。
- 仅取 4 个灯笼挂点放置暖色点光源，兼顾氛围与帧率。
- 阴影使用 2048 软阴影贴图，正交阴影相机覆盖整场。

## 操作

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 镜头默认自动巡览，交互时自动接管
