# 桌面微缩铁路小镇 (Alpine Junction Diorama)

基于 **Three.js** 构建的高品质桌面微缩 3D 铁道沙盘模型。呈现手工实体模型、地台切面以及微缩景观手办特有的温润质感（非体素/方块风格）。

---

## 🌟 项目亮点与特性

### 1. 实体沙盘与地层切面底座
- **深胡桃木工艺展示底座**：四周倒角实木包边，正面镶嵌黄铜金属铭牌 `VALLEY JUNCTION · 1928`。
- **地层截面切片 (Geological Strata Slice)**：侧面呈现草皮层、泥土层与岩石基底的手工切面，极具高档沙盘模型质感。
- **微缩等距透视视角 (Isometric View)**：采用低畸变视角，打开页面即可看清沙盘全貌与飞驰列车。

### 2. 有机规划的微缩小镇聚落
- **火车站系统**：包含欧式双层红砖站房、站台遮雨棚、候车长椅、复古站名挂牌、挂钟、行李推车以及车站进出站红绿双色信号机。
- **城镇主要建筑群**：四面钟楼市政厅、商业街（咖啡馆及露天桌椅、面包坊、复古旧书店）、阿尔卑斯双坡木屋、乡村花园洋房、河畔小屋。
- **河流与跨河大铁桥**：树脂般清澈翡翠绿水面、河床鹅卵石、河畔小木码头与木划艇；跨河段架设深墨绿钢铁桁架与石砌桥墩桥梁。
- **西北高耸丘陵与石砌隧道**：绿意盎然的丘陵草坡，山顶座落一座缓缓自转的古典风车，山体下方开凿石砌拱券铁路隧道，列车穿山而过。
- **基础设施与自然元素**：石砖市政广场与中心喷泉、道路路网、平交道口红白道闸栏杆、铸铁复古路灯、多种阔叶海绵树冠树、高山冷杉松树以及路旁停泊的复古微缩汽车。

### 3. 多节车厢独立切线转向铰接系统
- 由 **1 节蒸汽机车车头 + 2 节经典客车车厢** 组成。
- 采用沿轨道闭合曲线的双点弧长采样与法线正交基算法，每节车厢根据自身位置独立计算朝向与转向，转弯时呈现出自然逼真的铰接弯曲姿态，绝非整车刚体旋转。
- 车体细节丰富：机车圆柱锅炉、铜箍环、烟囱、驾驶室、车厢象牙白腰线、透光客车窗，车轮随行驶实时滚动自转。

### 4. 严谨的状态机与车站停留逻辑
- **到站停靠 2.0 秒**：列车进站平滑减速，到达车站停靠点整整停留约 2.0 秒（信号机亮红灯），2 秒倒计时结束后信号机变绿，平滑加速出站。
- **暂停冻结机制**：暂停时，车厢位移与 2 秒到站倒计时完全冻结；恢复播放后无缝继续计时与行驶。
- **速度无级调节与快捷预设**：支持 0.25x ~ 3.0x 连续调速，提供 0.5x, 1.0x, 2.0x 快捷按钮。
- **一键复位**：相机平滑飞回初始等距机位，列车位置重置到起点并恢复 1.0x 速度。

### 5. 昼夜环境光照与夜间发光系统
- **傍晚（默认 · Dusk）**：暖金色低角度斜阳、拉长柔和长阴影、紫粉色暮光天空与微缩沙盘温润质感。
- **白天（Day）**：清新明亮暖白阳光，草地与河面通透澄澈。
- **夜晚（Night）**：深蓝夜空与清冷月光（全景地貌与建筑轮廓依然清晰可辨）；小镇各民居与商铺窗户亮起温馨暖黄灯火，沿街复古路灯点亮并投射弱暖光，车站站台壁灯亮起，火车车头射出前照光束。

## 🚀 快速上手与运行

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器打开控制台输出的地址（通常为 `http://localhost:5173/`）。

### 构建生产包与预览
```bash
npm run build
npm run preview
```
构建产物将输出在 `dist/` 目录中。

## 🎮 操作与交互指南

| 交互动作 | 操作方式 | 功能说明 |
| :--- | :--- | :--- |
| **旋转沙盘** | 鼠标左键按住拖拽 | 自由 360 度观察沙盘各个角度 |
| **缩放视角** | 鼠标滚轮滑动 | 放大观察微缩细节，缩小看清全景 |
| **平移视图** | 鼠标右键按住拖拽 | 调整画面中心位置 |
| **运行 / 暂停** | 点击主控按钮 或 按 `[空格]` | 暂停/恢复列车（暂停时到站倒计时同步冻结） |
| **复位** | 点击【复位】按钮 或 按 `[R]` 键 | 平滑飞回初始机位、列车位置与默认速度 |
| **速度调节** | 拖动速度滑块 或 点击 `0.5x` / `1.0x` / `2.0x` | 调整列车行驶速度 |
| **光照切换** | 点击【傍晚】/【白天】/【夜晚】或按 `1` / `2` / `3` | 平滑过渡昼夜光照与发光状态 |
| **视角切换** | 点击【全景沙盘】/【火车站】/【跨河铁桥】/【追踪列车】 | 相机平滑飞行至指定观察机位 |

## 🔍 实测与功能验证报告

本项目已在本地完整执行了 TypeScript 类型检查、Vite 打包构建以及基于 Headless/GUI 浏览器的端到端自动化测试与视觉截屏验证：

1. **项目构建验证**：
   - 运行 `npm run build`，TypeScript 无类型错误，Vite 打包成功（用时 ~860ms），静态资源完整生成在 `dist/`。
2. **默认初始化验证**：
   - 打开页面立即呈现完整沙盘与默认傍晚暖色夕阳光照与长阴影。
   - 列车处于运行状态，平稳驶向火车站。
3. **车站停靠 2.0 秒实测**：
   - 浏览器高频采样时序记录显示：列车于 0.49s 进入进站减速，1.95s 精确停靠在火车站中心，信号机亮红灯，停留计时器从 2.0s 倒数至 0.0s，总停留时长 1.96 秒（约 2.0s）；3.91s 信号机恢复绿灯，列车平滑加速出站。
4. **运行与暂停冻结实测**：
   - 在停靠期间触发暂停（此时倒计时剩余 1.5s），等待 2.0 秒后实测验证：列车坐标未变（`distFrozen: true`），到站计时器未变（`timerFrozen: true`，数值维持在 0.55s）；恢复运行后继续平稳走完剩余 1.5s。
5. **速度调节与复位实测**：
   - 实测 0.5x、2.0x 倍速切换，运行速度线性响应；点击【复位】后，列车精确回到初始起始里程（误差 < 0.001），速度恢复 1.0x，相机平滑过渡回初始等距机位。
6. **昼夜切换与自发光实测**：
   - 切换到夜间模式，实测建筑窗户自发光强度从 0 提升至 2.0，路灯自发光强度提升至 2.5 并激活点光源漫反射，火车头大灯与聚光束激活，全场景在冷月夜空下清晰可见且氛围温馨。
