# 微缩铁路小镇 · Miniature Railway Town

一个用 [Three.js](https://threejs.org/) 实现的、可运行的桌面微缩铁路沙盘。火车沿一条**闭合轨道**运行，途经车站、建筑群、树木、路灯与一条跨河大桥；默认是带暖色阳光与投影的傍晚，可一键切换到夜晚。

无需后端，纯前端（原生 JS + Vite）。

## 特性

- **展示底座**：有厚度与边框的木质底座，草地、水面、模型建筑材质可辨认。
- **等距视角**：正交相机 + OrbitControls，默认机位即可看到全沙盘。
- **闭合铁路**：连续轨道（双钢轨 + 枕木 + 道砟），跨河处由桥梁结构承载。
- **完整小镇**：车站（含站台）、建筑群、河流与铁路跨河桥、树木、道路、路灯，整体被规划成聚落，而非零散摆放。
- **分节列车**：1 节车头 + 2 节车厢，每节**独立沿轨迹行驶**，转弯时保持合理间距与朝向（非刚体绕中心旋转）。
- **到站停留**：每次抵达车站停留约 2 秒再继续。
- **白天 / 夜晚**：夜晚车站、路灯与部分窗户发光，场景仍清晰可见。
- **交互**：运行/暂停、速度调节、复位、白天/夜晚切换；支持旋转、缩放；复位恢复确定的初始机位、列车位置与速度。

## 安装与启动

需要 Node.js 18+。

```bash
# 安装依赖
npm install

# 本地开发（热更新）
npm run dev

# 构建到 dist/
npm run build

# 预览构建产物
npm run preview
```

`npm run dev` 启动后，浏览器打开终端给出的本地地址（通常为 http://localhost:5173 ）即可直接看到完整沙盘与默认运行状态。

## 使用方式

- **暂停 / 运行**：暂停时车厢与到站计时同时冻结。
- **速度**：0.25× – 3× 连续可调。
- **复位**：恢复初始相机机位、列车位置与速度（1×），并恢复运行状态。
- **白天 / 夜晚**：切换光照与发光元素。
- **旋转 / 缩放**：鼠标拖拽旋转、滚轮缩放（正交相机下的缩放）。

## 实现说明

- 轨道由 `THREE.CatmullRomCurve3`（闭合）定义；钢轨用偏移曲线生成 `TubeGeometry`，枕木与道砟用沿曲线的 ribbon / 方块铺排。
- 列车位置用**弧长参数化**：每节车厢按各自距离偏移量从曲线上取点与切线，用 `lookAt` 对齐运动方向，因此转弯时各车厢自然跟随、间距稳定。
- 到站逻辑基于单调累计距离：当累计距离跨过“站点绝对位置”时停车 2 秒，再继续；暂停时不推进距离与计时。
- 河流为沿 X 轴的 ribbon，轨道在 `|z|<0.6` 且与 `|x|>6` 处与它相交，相交点自动生成带护栏与桥墩的桥梁。
- 白天/夜晚通过切换方向光、半球光、环境光强度与颜色，并开关窗户/路灯的自发光与路灯点光源实现。
- 布局使用固定随机种子，保证每次打开构图一致。
