# 体素宫城 · Voxel Palace

用 **Three.js** 实现的中国古典建筑群体素场景。纯前端、无后端，`npm install` 后即可构建运行。

打开页面即自动进入场景（相机自动巡航），无需任何操作即可看到建筑群全貌。

---

## 快速开始

```bash
npm install     # 安装依赖（three + vite）
npm run dev     # 开发服务器 → http://127.0.0.1:5199
npm run build   # 生产构建 → dist/
npm run preview # 预览构建产物 → http://127.0.0.1:5288
```

要求 Node ≥ 20.19（开发环境实测 Node 24.16 / npm 11.13 / Vite 8.3 / Three r186）。

## 场景内容

### 建筑群（13 座主体建筑，严格中轴对称）

| 建筑 | 形制 | 位置 | 说明 |
|---|---|---|---|
| 主殿 | **重檐庑殿顶**（黄琉璃） | 中轴 z=-34 | 七间、副阶、上下檐、正吻、匾额、丹陛、御栏 |
| 山门 | **重檐歇山顶**门楼 | 中轴 z=+90 | 三间拱券门洞前后贯通、门砧、踏跺 |
| 宝塔 | **楼阁式塔** 七层攒尖 | 中轴 z=-128 | 逐层收分、绿/黄琉璃相间、挑檐风铃、塔刹 |
| 钟楼 / 鼓楼 | 二层**攒尖顶** | x=±66, z=+68 | 内部悬钟 / 置鼓，四面开敞 |
| 东 / 西配殿 | **歇山顶**（青瓦） | x=±62, z=+20 | 五间、正面朝中庭、脊沿南北 |
| 东 / 西后配殿 | 歇山顶（缩尺 0.78） | x=±48, z=-90 | 后院配殿 |
| 东 / 西配廊 | **悬山顶**廊道 | x=±50, z=-33 | 连接配殿与主殿台基 |

另有红墙院墙（含琉璃瓦墙帽）、御河 + 平桥 + 栏板、华表、石狮、旗杆、铜香炉、石碑、松/槐古树。

### 中式形制细节

- **屋顶**：庑殿顶 / 歇山顶（山花）/ 攒尖顶 / 悬山顶；逐层同心环生成台阶状瓦面，瓦垄按 3 格节奏明暗交替
- **飞檐翘角**：檐角加厚 2×2×2，向外上方阶梯式挑出 4~5 级，末端套兽描金
- **正吻 / 垂脊**：正脊两端三级上翘戗脊
- **斗拱**：栌斗 / 华拱（挑出 2 格、拱端描金）/ 泥道拱 / 散斗，檐下成排
- **台基**：空心须弥座（下枋 2 层边框 + 身部 2 厚墙 + 台面），踏跺、垂带、御路石、望柱栏杆
- **柱网**：八角截面柱（3 格宽去四角，近似圆柱）+ 柱础
- **门窗**：棂格窗、门钉、槅扇、门槛；背立面直棂窗
- **色彩**：红墙 / 黄琉璃 / 绿琉璃 / 青瓦 / 木色构件 / 汉白玉

### 空间与地面

中轴御道（26 格宽，带御路石）贯通南北；横向道路连接各院；建筑周边石坪；院墙合围；御河横亘南端以平桥跨越。地面为宫城内精铺（2 格/格）+ 宫城外阶梯化高度场（10 格/格，带山脊扰动的远山与草甸灌木）。

### 光照与氛围

三套预设可 1.4 秒平滑切换：**晨曦 / 正午 / 暮色**，每套包含太阳高度角与方位角、日光/半球光/环境光颜色与强度、雾色与远近、天幕渐变、曝光、辉光强度、灯笼亮度。

- 低角度太阳 + 2048 PCFSoft 阴影贴图 → 长投影，光影层次清晰
- 线性雾 + 远景高度雾化 → 空气透视
- 暮色时窗纸与灯笼进入自发光层并点亮 6 盏点光源

## 技术实现

### 体素渲染管线

所有体素写入一张 `Map`（数值键编码），最终合并成 **单个 BufferGeometry**：

- **隐藏面剔除**：只发射朝向空邻居的面，内部面全部丢弃
- **逐角 AO**：每个面 4 顶点按 `side1 && side2` 规则采样邻域，叠加方向烘焙明暗
- **紧凑顶点格式**：位置 `Float32`、法线 `Int8 normalized`、颜色 `Uint8 normalized`（线性空间），索引 `Uint32`
- **地面单独走「顶面网格」**：2 格/格精铺 + 10 格/格阶梯高度场，避免逐体素铺地

### 为什么不用 EffectComposer

本机 ANGLE/D3D11 下 `UnrealBloomPass` 的加法混合会把整帧清成纯黑（已实测）。因此手写后期链：

```
场景 → HalfFloat RT（MSAA ×4）→ 亮部提取（阈值+软膝）
     → 可分离高斯（H/V ×2 轮）→ 最终 pass：辉光叠加 → 曝光
     → 冷暗部/暖亮部分离调色 → ACES 色调映射 → 暗角 → sRGB 编码
```

### 首帧保证

场景构建（体素生成 + 网格化）**一次性同步跑完**，随后**同步渲染首帧**并同步隐藏加载层——不依赖 `rAF` / `setTimeout` 推进。因此在标签页被挂起、计时器冻结的环境里也能立刻看到完成态画面。

### 分辨率自适应

后备缓冲总像素上限 **3.6M**：`pixelRatio = clamp(devicePixelRatio, 0.6, min(dpr, 1.75, sqrt(3.6e6 / cssPixels)))`。
不收敛的话，HalfFloat + MSAA 的 RT 在 4K / 高分屏下会把显存与驱动压力顶到临界点（实测 8.3M 像素时 GPU 进程直接卡死，3.7M 正常）。

### 交互

- 左键拖拽环视 / 滚轮缩放 / 右键平移（OrbitControls + 阻尼）
- 右上角：晨曦 / 正午 / 暮色切换、自动巡航开关、重置视角
- 左下角实时面板：帧率、体素数、可见面数、Draw Call / 三角面、渲染尺寸、场景生成耗时、GPU
- 手动操作后自动巡航暂停 7 秒再恢复

## 验收

```bash
npm run build
node scripts/verify.mjs --dpr 1                        # 1600×900
node scripts/verify.mjs --dpr 1 --width 2560 --height 1440 --tag qhd
node scripts/verify.mjs --dpr 1 --width 3840 --height 2160 --tag uhd
node scripts/verify.mjs --dpr 2 --tag hidpi
node scripts/test-voxel-key.mjs                         # 体素键编解码自检
```

`verify.mjs` 用 Node 内置 `http` 托管 `dist/`，拉起无头 Chrome（`--use-angle=d3d11`，真实 GPU），通过 CDP 注入 rAF 计数器测帧率、读 `window.__VOXEL` 状态、抓画布直出 PNG，并收集控制台报错。

> 注：内置浏览器在后台标签页会冻结 rAF 与定时器，帧率与截图不可信，故采用独立无头 Chrome。

页面暴露了验收接口：`window.__VOXEL.stats() / setPreset() / setCamera() / setPost() / capture()`。
