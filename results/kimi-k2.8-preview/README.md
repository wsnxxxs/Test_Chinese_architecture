# 体素 · 中国古典建筑群（Voxel Temple）

Three.js 实现的 Minecraft 式体素中国古典建筑群，Vite 构建，无后端，浏览器打开即看。

## 场景内容

- **主殿**：重檐庑殿顶，面阔五间，位于中轴线北端核心
- **东西配殿**：单檐歇山顶，三开间，对称分布于庭院两侧
- **山门**：五开间穿堂门，单檐歇山顶，位于场地南端入口
- **钟楼 / 鼓楼**：攒尖顶青瓦，方形平坐，分居庭院东南、西南（钟楼内悬铜钟）
- **环境**：中轴石板路（山门 → 庭院 → 主殿）、庭院广场、支路、石狮一对、灯笼、匾额、斗拱、台基台阶、环场树木、红墙矮墙
- **光影**：黄昏暖调，低角度暖阳 + 软阴影 + 雾效

## 运行

```bash
npm install
npm run dev
# 打开 http://localhost:5173
```

构建与预览：

```bash
npm run build     # 产物在 dist/
npm run preview   # 本地预览构建产物
```

## 技术要点

- 全部建筑由体素（1×1×1 方块）拼合：红墙、黄琉璃瓦、青瓦、木构、汉白玉台基
- 体素按颜色收集后每色生成一个 `InstancedMesh`——全场景约 1.5 万体素、约 20 个 draw call，旋转视角帧率稳定 60fps
- 屋顶算法：逐层收缩矩形 + 檐口外挑 + 四角抬高模拟飞檐翘角；庑殿顶带正脊鸱吻，攒尖顶收宝顶
- 门窗通过"后写覆盖"墙体体素实现，无需布尔运算

```
src/
  main.js            入口：渲染器 / 相机 / 灯光 / 循环
  palette.js         配色
  voxel.js           体素收集器 + InstancedMesh 批渲染
  parts.js           墙体 / 台阶 / 灯笼 / 屋顶等通用构件
  buildings/hall.js  殿宇（主殿重檐、配殿单檐共用）
  buildings/gate.js  山门
  buildings/tower.js 钟楼 / 鼓楼
  decor.js           树木 / 石狮
  layout.js          中轴布局：地面 / 道路 / 建筑群装配
```
