# 桌面微缩铁路镇 · Miniature Railway Town

一个用 **Three.js** 构建的桌面微缩铁路小镇沙盘：木质底座、闭合铁路、跨河桥梁、傍晚阳光、运行的小火车。打开页面即可看到完整沙盘和默认运行的列车。

![status](https://img.shields.io/badge/Three.js-r160-blue) ![vite](https://img.shields.io/badge/Vite-5-purple)

## 功能要点

- **沙盘构图**：木质边框底座 + 草地 + 弯曲河流 + 跨河石桥 + 闭合环形铁轨（枕木与钢轨分明）。
- **微缩小镇**：1 个主车站（带钟楼、站台、雨棚、路灯） + 7 栋风格各异的小屋 + 街道、围栏、行道树、路灯。
- **三节列车**：1 节蒸汽机车 + 2 节客车。每节车厢独立沿轨道曲线行驶，转弯时自动调整朝向，保持合理间距，不会当成刚体绕中心旋转。
- **默认傍晚**：暖色阳光、长投影、暖色雾气、木底座与草地、水面与建筑材质清晰可辨。
- **交互**：
  - 运行／暂停（暂停时列车与到站计时都暂停）
  - 速度调节（0.2× ~ 3×，滑块）
  - 复位（恢复初始机位、列车位置、速度）
  - 白天／夜晚切换（夜晚车站、路灯、部分窗户发光）
  - 鼠标拖拽旋转、滚轮缩放
- **到站停留**：列车每次抵达车站停留约 2 秒后继续运行。

## 安装与启动

```bash
# 安装依赖
npm install

# 开发服务器（默认 http://localhost:5173，可在 vite.config.js 中调整）
npm run dev

# 生产构建
npm run build

# 预览生产构建
npm run preview
```

> 如果 5173 / 4199 端口被占用，Vite 会自动选下一个空闲端口；如果你需要固定端口，可在 `vite.config.js` 中开启 `strictPort: true` 并指定端口。

## 使用说明

| 操作 | 效果 |
| --- | --- |
| 鼠标拖拽 | 旋转视角 |
| 鼠标滚轮 | 缩放视角 |
| 点击「暂停」 | 列车与到站计时全部冻结 |
| 拖动「速度」滑块 | 调整列车行驶速度 |
| 点击「复位」 | 列车回到初始位置，速度重置为 1.00×，相机回到默认机位 |
| 点击「白天 / 夜晚」 | 在白天 → 夜晚 → 傍晚 三档之间循环切换（默认先从「傍晚」开始切换） |

## 设计取舍

- **轨道运动**：使用 `THREE.CatmullRomCurve3`（闭合）作为轨道参数曲线，每节车厢按 `getPointAt(t)` 与 `getTangentAt(t)` 独立放置和定向，`t` 之间留有弧长对应的偏移以保持车厢间距。
- **桥面平整**：桥梁区域的曲线控制点近似共线，使列车过桥时不出现上下倾斜。
- **夜晚照明**：仅切换灯光预设与发光材质（窗户、路灯、时钟、车头灯）的 `emissive`，无需重建场景。
- **沙盘风格**：使用 `MeshStandardMaterial`（含 PBR 粗糙度／金属度）模拟木质、混凝土、漆面、玻璃等表面；通过顶点色微调草地与水面，避免整体过于单一。
