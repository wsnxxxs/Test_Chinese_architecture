# Form 68

原创 68 键机械键盘的交互式展示与配置页面。使用 Vite、原生 JavaScript、Three.js；配置界面由普通 HTML/CSS 构成，不需要后端或外部模型文件。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址。生产构建与本地预览：

```sh
npm run build
npm run preview
```

## 使用

- 拖动模型旋转，滚轮或双指捏合缩放；预览区右下角也提供缩放、视角复位按钮。
- 三种 Case finish 和三种 Keycap palette 可自由组合，模型与 Your configuration 摘要即时同步。
- Explore the layers 平滑展开键帽、定位板和外壳，Bring it together 重新组装。连续点击使用绝对位置作为动画目标，不会累加位移。
- 打开 Give it a try，按 A–Z 或空格体验键帽下压；鼠标、触屏也可直接点按键帽。可选合成按键声音默认关闭。输入框、文本域、可编辑区域保持正常输入；聚焦按钮时空格保留原生按钮操作。
- Save your configuration 将当前配色保存到此浏览器，刷新自动恢复。修改后显示 Unsaved changes，需再次保存。
- Restore defaults 恢复 Chalk / Studio，并且只删除 `form68.config.v1` 这一项本地配置，不影响其他网站数据。

## 实现说明

模型共 68 枚键帽、五行布局，含数字行、字母、方向键和不同宽度的修饰键。程序化创建圆角壳体、内凹底座、定位板、垫片、轴座、螺丝与键帽，字符通过模型表面的纹理显示。Three.js 分组管理三层结构，统一渲染循环驱动拆解、视角和按键动画。窗口变化时适配模型构图；界面支持桌面和移动端，并遵循减少动态效果偏好。

界面字体通过 Fontsource 随项目打包，同时保留系统字体回退。模型、字体、配色和交互不依赖第三方资源服务。3D 预览需要支持 WebGL 的浏览器；无法初始化时会显示提示，配置控件仍可使用。

这是原创产品概念展示，不含购买、支付或真实硬件连接功能。按键声音为 Web Audio 合成效果。

## 已执行的验证

- `npm install` 成功；`npm run build` 成功，生成 `dist/`，构建无警告。
- 在 Chromium 中确认模型包含 68 枚键帽，检查桌面截图及 390px 移动端布局。
- 通过界面遍历全部 9 种配色组合，确认配置摘要与键帽主题同步。
- 保存后刷新可恢复配置；恢复默认仅删除本页存储项，其他测试存储项保持不变。
- 连续切换拆解/组装后，两层移动结构回到原始位置。
- 实际发送 A、Z、空格键事件，检查键帽下压；输入框聚焦时可以正常输入。
- 验证鼠标旋转、缩放、视角复位和移动端无横向溢出。
- 使用 Chromium 的触屏模拟点按 A 键，确认体验反馈更新。未在实体手机上测试。

界面字体的开源许可位于 `public/font-licenses/`，会随构建产物分发。
