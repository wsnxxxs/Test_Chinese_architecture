# ORBIT 68

原创机械键盘的交互式产品展示与配置页面。使用 **Vite + 原生 HTML/CSS/JavaScript + Three.js**，无需后端。

## 启动

建议使用 Node.js 22.12 或更新版本。

```bash
npm install
npm run dev
```

打开终端输出的本地地址。默认端口为 5173；已被占用时，Vite 会选择下一个可用端口。也可指定：

```bash
npm run dev -- --port 5286 --strictPort
```

## 构建与预览

```bash
npm run build
npm run preview
```

生产文件位于 `dist/`，可以部署到静态网站托管服务。三维模型程序化生成，字体由 npm 包提供，不依赖外部模型、图片或字体 CDN。预览需要支持 WebGL 的现代浏览器。

## 使用方式

- **配色**：选择三种外壳与三种键帽主题，可自由组合为九种配置。三维材质、选中标记、预览标签与配置摘要同步更新。
- **视角**：拖动模型旋转，滚轮缩放；手机支持单指旋转、双指缩放。模型下方提供放大、缩小和复位按钮。
- **拆解／组装**：展开键帽、带有轴体的定位板及底壳。动画始终朝当前目标位置过渡，可在动画中连续反向切换。
- **键盘体验**：打开体验开关，按下 A–Z 或空格，或点按屏幕上的任意键帽。键帽下压并回弹，面板显示最近敲击的键。按住实体按键时保持下压，窗口失焦或关闭体验时释放。空格用于操作已聚焦的按钮时，保留按钮正常行为。
- **声音**：体验模式中的扬声器按钮可开启合成敲击声音，默认为关闭。
- **保存**：点击「保存我的配置」后，外壳与键帽配色存储在当前浏览器中，刷新页面时恢复。修改配色后需再次点击保存。旋转角度、拆解状态、声音及体验开关不持久化。
- **恢复默认**：仅删除 `orbit68.configuration.v1` 这一条本地存储，恢复雾银外壳与植物园键帽，不调用 `localStorage.clear()`。

键盘体验的按键监听会跳过输入框、文本区域、下拉控件及可编辑区域，以及 Ctrl、Command、Alt 组合键。

## 模型与文件

五行、68 键的紧凑布局，包含数字行、完整字母区、方向与导航键，以及不同宽度的空格、回车、Shift 和退格键。键帽具有圆角、肩部、字符与独立行程；机身具有 6° 倾角、上下壳接缝、脚垫、螺丝、USB-C 接口与品牌标记。拆解后可见轴座、轴心、稳定器与简化电路板。

```text
src/main.js      HTML 界面、配置状态、存储、键盘事件与合成声音
src/keyboard.js  Three.js 模型、材质、视角、射线拾取与动画
src/style.css    视觉样式及桌面／手机响应布局
```

配置界面为原生 HTML 控件。Canvas 仅用于三维渲染与模型表面字符纹理。
