# 桌面微缩铁路小镇 · Miniature Railway Town

用 **Three.js + Vite（原生 JS）** 制作的桌面沙盘：木框底座上的闭合铁路环线、河流与两座跨河铁路桥、车站、约六十栋建筑，
以及一列 1 机车 + 2 客车、每节车厢独立沿轨道行驶的蒸汽小火车。无后端，所有贴图均由 Canvas 程序化生成（无外部资源）。

## 安装与运行

```bash
npm install
npm run dev        # 开发模式，默认 http://localhost:5173
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览构建结果
```

需要 Node.js 18+。打开页面即可看到完整沙盘，列车已在运行（默认傍晚暖阳 + 投影）。

## 交互

| 操作 | 说明 |
| --- | --- |
| 左键拖动 / 滚轮 / 右键拖动 | 旋转 / 缩放 / 平移视角（俯仰与平移范围有限制，不会钻到桌面下） |
| **运行 / 暂停**（空格） | 暂停时车厢、烟雾、道口栏杆与"到站停留计时"全部冻结 |
| **列车速度**滑条 | 0.25×–3×；只影响行驶速度，到站停留仍约 2 秒 |
| **复位**（R） | 恢复确定的初始机位、列车位置、速度 1×、运行状态（不改变昼夜设置） |
| **白天 / 夜晚**（N） | 平滑过渡；夜晚车站、路灯、列车前灯发光，部分窗户亮起 |

列车每次抵达车站站台会平稳减速停靠约 2 秒（面板上显示剩余秒数），再加速离站。

## 场景与实现要点

- **底座**：带倒角的挤出木框（木纹 + 凹凸）、黄铜包角和铭牌、底托与桌面；地形为高度场，河道下切并带岸坡。
- **铁路**：以 `CatmullRomCurve3` 生成闭合曲线（南侧站台段为直线），按弧长重采样；道床、双钢轨（真实截面）、枕木沿同一曲线扫掠生成，
  因此轨道处处连续。铁路两次跨河：**南侧石拱桥**、**北侧钢桁架桥**；道路跨河有木桥与石桥；南侧有一处带栏杆、红灯的**平交道口**，
  列车接近时栏杆自动放下。
- **列车**：机车与两节客车各自取"前后转向架"两个弧长位置，车体位置取二者中点、朝向取二者连线，
  因此转弯时各节车厢独立沿轨迹行驶并保持恒定间距；轮对随行驶距离转动，机车连杆随轮转动，烟囱冒烟。
- **小镇规划**：车站广场（喷泉）→ 站前大道 → 镇中心大街 → 后街，外环路经道口与南岸相连；市政厅、教堂、商铺、咖啡馆、邮局、
  仓库、水塔、河东农庄（风车、谷仓、羊群）等。建筑全部避开铁路与河岸（页面加载时自动做占地自检，结果输出在控制台）。
- **材质与灯光**：石膏墙、瓦片、砖、碎石道床、静电草地（程序化贴图 + 凹凸）；暖色方向光 + 4096 阴影贴图 + 半球光 + 环境反射。
- **性能**：树木/枕木/窗户/路灯使用 `InstancedMesh`；建筑与道具的静态小网格按材质合并（绘制调用由约 1700 降到约 550，含阴影通道）。

## 目录结构

```
src/main.js       入口：渲染器、相机、UI、主循环
src/world.js      铁路曲线、河流、道路等数据与几何查询
src/terrain.js    木框底座、地形高度场、河面
src/textures.js   程序化贴图（含整块地面彩绘）
src/materials.js  共享材质与发光材质
src/track.js      道床/钢轨/枕木、桥梁、道口
src/buildings.js  建筑工厂     src/town.js  总体布局
src/scenery.js    树木、路灯、汽车、羊群等
src/train.js      列车模型与运动状态机
src/lighting.js   昼夜光照     src/optimize.js  静态网格合并
```

  运行/暂停、速度滑条、复位、昼夜按钮的状态变化正确。

  单步位移无跳变；到站停留 2.02 s；暂停期间位置不变；复位后回到相同初始位置与相机。
