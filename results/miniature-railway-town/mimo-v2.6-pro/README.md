# 青溪镇 · 桌面微缩铁路沙盘

木质底座上的青溪镇，钢桁架桥与石拱桥连接闭合铁路，三节列车独立沿轨道运行。 使用 Three.js、原生 HTML/CSS/JavaScript 和 Vite；材质与模型由项目代码生成，无需后端。

## 安装与运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
npm run build
npm run preview
```

构建使用相对资源路径，可部署在子目录中。

## 操作

- 左键拖动旋转，滚轮或双指缩放，右键拖动平移。
- 运行或暂停按钮控制列车，速度滑杆可调整到 0.25×–3×。
- 昼夜按钮切换白天和夜晚；空格暂停，R 复位，N 切换昼夜。
- 复位按钮恢复初始机位、列车位置与默认速度。
- 列车由车头与两节车厢组成，在车站短暂停留后继续行驶。
