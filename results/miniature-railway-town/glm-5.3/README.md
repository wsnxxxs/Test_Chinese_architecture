# 枫屿镇 · 桌面微缩铁路小镇沙盘

基于 **Three.js**（原生 JS + Vite）的可交互 3D 微缩沙盘：一块带边框的实木展示底座上，
闭合窄轨铁路环绕小镇，蒸汽小火车（1 节车头 + 2 节车厢）沿轨独立运行，每次抵达车站
减速停靠约 2 秒后继续行驶。河流从镇中穿过，铁路在北、南两处以钢板梁桥跨河，主街经
公路桥过河、在东直段以平交道口穿越铁路，联系东岸小村。

## 安装与启动

```bash
npm install
npm run dev
```

启动后访问 **http://127.0.0.1:15103** （端口在 `vite.config.js` 中锁定为 15103，
`strictPort` 开启，不会自动换端口）。

生产构建与预览：

```bash
npm run build     # 输出到 dist/
npm run preview   # 同样固定 127.0.0.1:15103
```

## 使用说明

| 操作 | 方式 |
| --- | --- |
| 运行 / 暂停 | 左上面板「暂停 / 继续」按钮（暂停时列车与到站计时同步冻结） |
| 速度调节 | 面板滑杆，0.25× – 3× |
| 复位 | 「复位」按钮：恢复初始机位、列车位置、速度 1×、运行状态与傍晚光照 |
| 白天 / 夜晚 | 「切换夜晚 / 切换白天」按钮，约 1 秒过渡；夜晚车站、路灯、车灯与部分窗户发光 |
| 视角 | 左键拖拽旋转、滚轮缩放、右键平移 |

页面打开即为傍晚暖光场景：完整沙盘一览，列车默认运行中，并很快演示一次进站停靠。

## 场景构成

- **底座**：实木厚板 + 抬高边框 + 正面黄铜铭牌，草地与河岸为切割成型的地形板；
- **铁路**：直线 + 圆弧拼合的闭合环线（`CurvePath`），道砟梯形截面缎带、实例化轨枕、
  双侧铁轨偏移管；两座下承式钢板梁桥（桥墩落于河床）、一处平交道口（带道口标志）；
- **小镇**：车站（站台、雨棚、站牌、信号机、水塔）、镇公所（钟楼）、教堂、工厂、
  货棚、谷仓、商铺与凉亭、15 栋住宅；主街 / 十字街 / 站前广场 / 喷泉小广场、公路桥、
  树木（实例化，阔叶 + 针叶）、灌木花丛、路灯、栅栏、田地草垛与木钉小人；
- **列车**：三节车辆各自沿曲线取位，以「前后挂钩连线」确定朝向，过弯自然呈弦线姿态；
  蒸汽机车带烟囱粒子与夜间前照灯，客车窗夜间点亮。

## 技术说明

- Three.js r170，`MeshStandardMaterial` + 程序化 Canvas 纹理（草地色斑、木纹、田垄、
  站牌 / 铭牌 / 钟面），无外部模型与后处理依赖；
- 单张 2048 阴影贴图（PCFSoft）；树木、轨枕、花灌均使用 `InstancedMesh` 控制绘制调用；
- 昼夜切换通过统一注册表插值（灯光颜色 / 强度 / 自发光 / 光晕透明度）+ 页面背景
  渐变过渡实现；
- 布局使用固定种子随机数，每次打开完全一致；`window.__app` 暴露状态与控制接口，
  便于自动化验收（页面错误收集在 `window.__errs`；`__app.simulate(秒数)` 可同步推进
  仿真逻辑而不依赖真实渲染帧，适用于嵌入式浏览器等 rAF 受限环境下的功能验证）；
- 渲染循环首选 `requestAnimationFrame`，若前 2 秒帧数异常（部分嵌入式浏览器会冻结
  或极低频率投递 rAF），自动降级为定时器驱动，保证列车持续运行。

## 已验证内容（2026-09-26，本机实测）

- `npm run build` 构建通过；`npm run dev` 固定监听 `127.0.0.1:15103`；
- 页面零运行错误；初始画面完整呈现沙盘（底座四角无裁切）与运行中的列车；
- 列车每圈进站停靠约 2 秒后加速出站；暂停时列车位置与到站计时完全冻结；
- 速度滑杆实时生效（2× 下同时间段位移为 1× 的两倍）；
- 夜晚模式：路灯、部分窗户、车站、列车车窗与前照灯发光，场景仍可看清；
- 复位恢复初始机位、列车位置（s≈82.2）、速度 1×、运行状态与傍晚光照。

注：以上交互逻辑在 ZCode 应用内嵌浏览器（页面被标记为 hidden、rAF/定时器被
系统节流）中通过 `__app.simulate` 验证；在常规可见浏览器中将由真实渲染循环执行
同一套逻辑。
