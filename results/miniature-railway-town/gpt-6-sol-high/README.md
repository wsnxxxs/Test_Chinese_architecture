# 松溪镇 · 桌面微缩铁路

一个使用 Three.js 制作的桌面微缩铁路小镇。场景包含有边框的实体沙盘、闭合轨道、两处跨河铁路桥、车站、街区、道路和夜间照明。列车由车头与两节车厢组成，每节车厢沿轨道独立跟随并在车站短暂停留。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

在终端显示的本地地址打开页面。生产构建使用 `npm run build`，预览构建使用 `npm run preview`。

## 使用方式

- 鼠标拖动旋转视角，滚轮缩放；触屏可拖动和双指缩放。
- 控制台可暂停／继续、调整速度、切换白天／夜晚。
- 复位恢复初始机位、列车位置、运行状态、白天模式和 1.0× 速度。
- 列车每次到站停留约两秒；暂停时停站计时也暂停。
