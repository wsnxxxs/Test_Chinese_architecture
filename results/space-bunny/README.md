# 云麓宫 · 体素汉风建筑群（Three.js）

> 已作为 Space-bunny 作品收录；按用户要求暂时归入 MiniMax。模型归属尚未核实。

> 接入验证（2026-09-25）：已在本站工作区构建，并通过内嵌预览实际打开 Three.js 场景；随附的六张截图保留为作者预览图。

一个可直接运行的 **Three.js 体素（Voxel）风格中国古典建筑群** 场景：中轴对称的宫城布局，
包含主殿、配殿、山门、钟楼、鼓楼、宝塔、角楼、廊庑与宫墙，配护城河、御道、庭院铺装与绿化。
页面打开即自动进入场景并缓慢巡游，支持晨 / 暮 / 夜三套光照色调。

---

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 本地开发（http://127.0.0.1:5273）
npm run dev

# 3. 生产构建，产物在 dist/
npm run build

# 4. 预览构建产物（http://127.0.0.1:4273）
npm run preview
```

> 端口已固定为 5273 / 4273（`--strictPort`），避免与本机其它前端服务冲突。

### 可选：自动化验收

```bash
npm run build
node scripts/verify-fps.mjs          # 6 个场景：测帧率 + 抓图到 verify-shots/
node scripts/verify-fps.mjs --quick  # 只跑第一个场景，快速回归
```

脚本用系统 Chrome（headless=new + 真实 GPU）通过 CDP 实测渲染帧率、读取 draw call / 三角面数、
收集控制台报错，并批量输出截图与 `verify-shots/report.json`。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 滚轮 | 推拉镜头 |
| 右键拖拽 | 平移 |
| 数字键 `1` / `2` / `3` | 切换 晨 / 暮 / 夜 |
| 右上角按钮 | 切换时辰与机位（全景 / 山门 / 主殿 / 鸟瞰） |

镜头默认自动巡游；一旦手动操作，静止 12 秒后自动恢复。

### URL 参数

```
?time=morning|dusk|night          时辰
?view=overview|gate|hall|aerial   机位
?paused=1                         关闭自动巡游
?dpr=1.5                          限制渲染像素比
```

## 场景内容

### 建筑群（严格中轴对称，x = 0 为中轴，+z 为南）

```
        北  z=-62 ┌───────────── 宫墙 ─────────────┐
                  │             宝 塔               │  十层攒尖 + 塔刹
                  │          （主殿之后制高）         │
                  │             主 殿                │  z=-32  重檐庑殿顶 · 面阔七间
        配殿 ┐    │  ┌──────── 主殿前广场 ────────┐  ┌ 配殿│  z=-2   歇山顶 · 门朝中轴
        廊庑 ┘    │  │          中轴御道          │  └ 廊庑│  z=-22~8
                  │      钟 楼        鼓 楼      │        │  z=24   两层楼阁 · 攒尖顶
                  │         门前广场              │        │
                  └────────── 山 门 ─────────────┘        │  z=38   三间门洞 + 城楼
        南  z=42 └───────────── 宫墙 ─────────────┘
```

四角另有 **角楼** 4 座，宫墙外为 **护城河 + 石桥 + 御道**，再外侧是防护林、远山与草地。

### 建筑形制与细节

- **屋顶**：庑殿顶（主殿，重檐）、歇山顶（配殿，含山花）、攒尖顶（钟鼓楼 / 角楼）、塔檐收分（宝塔）；
  逐层内收形成 45° 瓦坡，檐口亮色瓦当、檐角起翘并以琉璃色收头，正脊两端带鸱吻。
- **木构**：檐柱、柱础、**柱头箍**、额枋（青绿彩画）、**斗拱**（两跳出挑 + 散斗 + 昂嘴）、檐下椽子。
- **门窗**：隔扇门（板门 + 门钉 + 门簪 + 格心）、槛窗（窗棂 + 窗纸），夜间窗纸透出暖光。
- **石作**：须弥座台基、踏跺与御路、勾栏（望柱 + 扶手）、石桥驳岸、牌坊式华表。
- **小品**：石狮、铜香炉（内有火光）、太湖石、花坛、行道树与灯杆。
- **灯火**：主殿、配殿、山门、廊庑檐下逐间挂灯，宝塔每层檐角悬风铃。

### 环境与光影

- 方向光 + 半球光 + ACES 色调映射，4096 阴影贴图（PCFSoft），夜间自动关闭平行光硬阴影。
- **晨**：低角度暖阳、青蓝天空、淡雾；**暮**：橙红夕照、暖雾；**夜**：月光 + 灯笼 / 窗纸 / 香炉自发光、
  暖色点光源、星空与萤火虫。
- 渐变天空球（含日晕）、漂移体素云、萤火虫粒子、护城河水面（三档深浅蓝）。
- 郊野铺陈：宫墙之外有田块、树丛、裸土斑块与低缓地形起伏，远处只留两圈山影做天际线。

```
│   ├── palette.js             调色板 + 颜色明暗/抖动/确定性随机工具
│   ├── voxel.js               体素世界：Map 累积 → InstancedMesh（solid / lantern / window）

```

## 性能

整座城一次性烘焙进 **3 个 InstancedMesh**（建筑本体 / 灯笼 / 窗纸），加上天空、云、粒子与光晕，
draw call 稳定在 100 以内。

实测（本机 RTX 4070 Laptop，1600×900，headless Chrome 通过 CDP 实测 5 秒 rAF）：

| 指标 | 数值 |
| --- | --- |
| 体素实例数 | 41,910 |
| draw call | 31（晨）/ 89（暮·夜，含灯火光晕贴片） |
| 三角面 | 505,038 |
| 帧率 | **165 FPS**（晨 / 暮 / 夜实测） |
| 控制台报错 | 0（6 个场景全部通过） |

远高于 ≥30 FPS 的要求；低端设备可用 `?dpr=1` 进一步降低像素比。

验收覆盖 6 个场景（晨/暮/夜全景、山门、主殿、鸟瞰），截图与 `report.json` 输出在 `verify-shots/`。

## 技术栈

Three.js r160（`InstancedMesh` / `ACESFilmicToneMapping` / 自定义天空 `ShaderMaterial`）+
Vite 6，原生 JavaScript，无后端、无其它运行时依赖。
