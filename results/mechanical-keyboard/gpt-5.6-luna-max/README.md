# Sora Atelier 75

一个使用 Three.js 制作的原创机械键盘产品展示与配置页面。页面以正常 HTML/CSS 承载配置界面，Three.js 只负责键盘模型与模型交互。

## 安装与启动

需要 Node.js 18+。

```bash
npm install
npm run dev
```

然后打开 Vite 输出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 使用方式

- 点击左侧外壳和键帽主题，实时组合出三种外壳与三种键帽主题；配置摘要会同步更新。
- 在模型上拖拽旋转、滚轮缩放，或使用底部的旋转/复位视角按钮。
- 点击“拆解结构”，在键帽、定位板、底壳三层之间展开；再次点击即可复原，连续快速点击也会以最新目标状态收敛。
- 在页面空白处按 A—Z 或空格，或者直接点击模型上的对应键帽，观察按下与回弹。
- 点击“保存配置”写入当前浏览器的本地存储；刷新页面会恢复。 “恢复默认”只移除本页面使用的配置记录。

## 验证说明

已执行 `npm install` 与 `npm run build`。本项目没有后端服务；配置保存使用浏览器 `localStorage`。
