# LUMEN 68 · 紧凑机械键盘 交互式展示与配置页

原创机械键盘「LUMEN 68」的产品展示页面：首屏同时呈现产品名称、简介、完整 3D 键盘与主要配置控件。
3D 场景由 **Three.js** 渲染，配置界面是正常的 HTML/CSS 控件（没有把界面画进 Canvas）。

![tech](https://img.shields.io/badge/three.js-r169-blue) ![build](https://img.shields.io/badge/vite-5.x-yellow)

## 安装与启动

```bash
npm install      # 安装依赖（three + vite）
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览构建产物，默认 http://localhost:4173
```

无后端、无外部资源请求（环境反射使用 three 自带的 `RoomEnvironment`，字符为运行时 Canvas 纹理），
安装后可直接启动与构建。

## 页面与产品

- **LUMEN 68**：68 键 / 5 行紧凑布局（ANSI 65%），含字母区、数字行、方向键，
  以及不同宽度的空格（6.25u）、回车（2.25u）、Shift（2.25u / 1.75u）、Backspace（2u）。
- 键帽具备高度、圆角、顶部内收与微凹面，键帽之间保留缝隙，字符为可读图例（1–0、A–Z、TAB、ENTER、←↑↓→、LUMEN 刻字等）。
- 定位板带轴孔，轴体（上盖 + 十字轴心）嵌在板上；底壳是带厚度、倒角与 **6° 倾角**的楔形外壳，顶框包住定位板，三层结构可辨认。

## 配置能力

| 配置项 | 选项 | 说明 |
| --- | --- | --- |
| 外壳配色 | 石墨黑 / 月岩银 / 深海蓝 | 影响底壳材质（颜色、金属度、粗糙度） |
| 键帽主题 | 晨雾白 / 碳影黑 / 复古米 | 双色键帽 + 强色键（Esc/Enter/空格）+ 字符颜色 |
| 轴体 | 红轴 / 茶轴 / 青轴 | 轴心颜色与按压行程手感 |
| 空格刻字 | 最多 10 字符 | 实时更新空格键字符 |

外壳配色与键帽主题可 **任意组合**，3D 预览与右侧「配置摘要」实时同步。

## 交互说明

- **视角**：拖拽旋转、滚轮/双指缩放，`复位视角` 平滑回到初始 3/4 展示角度，`自动旋转` 为环绕展示。
- **拆解 / 组装**：在「键帽 / 定位板 / 底壳」三层之间平滑展开与复原。动画按帧指数逼近目标位置，
  **快速反复点击最终仍精确落位**。
- **键盘体验模式**（默认开启）：
  - 实体键盘按下 `A–Z`、空格（以及方向键），对应键帽下压并回弹；
  - 触屏/鼠标可直接点按 3D 键帽体验；
  - **输入控件获得焦点时（如空格刻字输入框、按钮）不劫持正常输入**，输入框内打字不会触发键帽动画。
- **保存配置 / 恢复默认**：
  - 配置改动即写入 `localStorage`（键名 `lumen68:config:v1`），点「保存配置」立即保存并提示；
    刷新页面后配色、轴体、刻字与配置摘要自动恢复。
  - 「恢复默认」**只移除本页面自己的配置键**，不影响其它站点/应用的存储。

## 实现要点

- **键帽几何**：细分盒 + 「内核外推」倒角（保留顶面内部顶点），再做上沿内收与顶部凹面；
  字符贴片沿同一凹面贴合，避免悬浮或被键帽遮挡。
- **底壳倾角**：对挤出几何做按高度线性偏移，底面保持水平、顶面后缘抬升 6°，定位板与键帽组按同一角度摆放。
- **动画**：拆解与按键回弹均为「当前值 → 目标值」的指数逼近（时间步长自适应），
  任意时刻切换目标都能收敛，连点不会错位；拆解在阈值内精确落位。
- **性能**：68 枚键帽按尺寸缓存几何、字符纹理运行时生成；轴体/轴心合并为单次绘制；总绘制调用约 142 次。

## 验证情况

已执行并确认（Chrome 内核浏览器实测）：

- `npm install`、`npm run build` 均通过（Vite 5.4 + three 0.169，构建产物约 544 KB / gzip 142 KB）。
- 页面首屏渲染：产品名、简介、完整键盘（含全部字符）、配置控件同时可见；加载遮罩在首帧渲染后消失。
- 配色/主题/轴体组合切换：3D 材质颜色、轴心颜色、配置摘要、选中态实时同步（含 3×3×3 组合中的多组抽样）。
- 拆解/组装：动画收敛数值验证（1 秒收敛、连点 7 次后精确回到 0），并截图确认键帽/定位板/底壳三层展开效果。
- 按键体验：`KeyA/KeyZ` 等事件使键帽目标值置 1、回弹归零（下压深度随轴体变化）；
  空格刻字输入框聚焦时按键事件不触发键帽、输入内容正常。
- 保存/恢复：配置写入 `localStorage` → 刷新后完整恢复（配色、刻字、摘要、状态标识）；
  「恢复默认」仅删除 `lumen68:config:v1`，同时保留了预先放置的其它存储键。

未逐项验证 / 已知说明：

- 真机触屏点击键帽使用与鼠标相同的 Pointer Events 逻辑，未在实体触屏设备上实测。
- 浏览器自动化环境无法向页面注入真实点击/按键（页面事件监听未收到注入事件），
  因此交互验证通过页面内派发 DOM 事件 + 数值断言完成；真实鼠标/键盘路径为同一套事件处理器。
- 自动化后台标签页会节流 `requestAnimationFrame`，动画收敛验证是手动步进模拟时间完成的；
  前台浏览时动画按 60fps 运行。
