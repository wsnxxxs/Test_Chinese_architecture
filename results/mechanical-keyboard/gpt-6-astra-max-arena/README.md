# Forma 68

原创机械键盘交互展示与配置页面。使用 React、TypeScript、Vite、Three.js 和 Motion 构建，无需后端、API 密钥、外部模型或图片服务。所有配置操作均为普通 HTML 控件，Canvas 只负责三维产品。

## 安装与启动

建议使用 Node.js 22.12 或更高版本。Vite 7 也支持 Node.js 20.19 及以上版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认通常为 `http://localhost:5173`。

## 构建与预览

```sh
npm run build
npm run preview
```

生产输出位于 `dist/`。项目沿用工作区预设的 `vite-plugin-singlefile`，将 JavaScript 和 CSS 内联到 `dist/index.html`；图标来自 `public/favicon.svg`。部署整个 `dist/` 到静态托管即可。请通过 HTTP 服务访问，不建议直接使用 `file://`，以保证本地存储行为一致。

## 使用方式

1. 外壳有雾白、岩墨、鼠尾草三种配色；键帽有原点、夜航、苔原三种主题，可自由组合为九种搭配。
2. 鼠标拖动旋转，滚轮缩放；触屏单指旋转、双指缩放。底部的加减按钮也可缩放，圆形箭头复位视角。
3. 点击“拆解探索”展开键帽、定位板和底壳；再次点击“组装键盘”还原。动画过程中可以连续反向切换。
4. 打开“键盘体验”后，使用实际键盘的 A-Z 或空格，或点击/轻触任意三维键帽。物理按键按 QWERTY 键位的 `KeyboardEvent.code` 映射；支持多个字母同时按住。
5. 按键音默认关闭，可通过体验开关旁的扬声器单独开启。音效为浏览器合成的演示音，不代表真实硬件录音。
6. 点击搭配名称可直接编辑。在输入框、选择控件、可编辑区域或指南弹窗中输入时，不会触发全局试按，也不会阻止正常输入、输入法或系统组合键。
7. 点击“保存我的搭配”保存外壳、键帽和名称。刷新页面会还原最后一次主动保存的配置；未保存的修改不会自动持久化。
8. “恢复默认”会清除本页面自己的存储记录，并还原默认配色、视角和体验开关。不会使用 `localStorage.clear()`，也不会删除其他页面的数据。

## 模型与实现

- 五行共 68 枚独立键帽，包含完整字母区、数字行、四个方向键以及 6.25u 空格、2.25u 回车、2.25u/1.75u Shift。
- 键帽有圆角、收口侧壁、独立字符贴图、间隙、定位凸点和可独立下压的行程。
- 底壳包含有厚度的开口边框、底板、脚垫、前沿品牌标记及 USB-C 接口；整体采用六度倾角。
- 定位板使用真实开孔的挤出几何体，带轴体、轴心、螺丝和长键平衡结构；底壳内还有程序化电路板纹理。
- 场景按 `shell`、`plate`、`caps` 分组。拆解由单一连续进度计算绝对位置，没有累积位移或堆积的动画队列，因此快速切换不会改变最终装配位置。
- Three.js 的逐帧循环管理视角、颜色插值、拆解和按键行程，不将每帧数据放入 React 状态。
- 重复轴体使用实例化渲染，共享几何与材质；阴影只在模型发生位移时刷新。渲染像素比最多为 2，页面隐藏或产品不在视口时跳过绘制。
- 松键、窗口失焦、进入输入控件、隐藏标签页、关闭体验时会释放按键。触摸点击与拖拽按位移和时长区分。
- 尊重系统的减少动态效果偏好。WebGL 不可用或上下文丢失时显示重试提示，HTML 配置功能仍保留。
- 卸载场景时清理动画帧、监听器、观察器、音频上下文、纹理、材质、几何体和 WebGL 资源，兼容 React Strict Mode。

## 本地数据

唯一存储键为 `forma68:configuration:v1`，内容包含版本和配置。读取时校验版本、选项 ID 和名称，损坏或不支持的数据会退回默认配置。保存/清除失败时显示明确提示，不会假装保存成功。

这个项目不会发送按键、名称或配色信息到服务器。不请求远程字体、图片、模型或音频。键盘、外壳材质和规格均为原创产品概念演示，不是实际销售或硬件连接功能。
