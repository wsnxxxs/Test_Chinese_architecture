# 微缩铁路小镇 (Miniature Railway Town)

用 Three.js 制作的桌面微缩铁路沙盘：一块带木质边框的展示底座上，一条闭合铁路环绕小镇运行，一列由车头和两节车厢组成的小火车沿轨道行驶，途经河谷上的两座桁架桥，并在车站停靠。

## 运行

```bash
npm install
npm run dev      # 默认 http://localhost:5173
```

打开页面即可看到完整沙盘与运行中的列车（默认傍晚暖光）。

## 构建

```bash
npm run build    # 输出到 dist/
npm run preview  # 预览构建产物
```

## 交互

| 操作 | 方式 |
| --- | --- |
| 旋转 / 缩放 / 平移 | 鼠标左键拖动 / 滚轮 / 右键拖动 |
| 运行 / 暂停 | 左下角「暂停 / 运行」按钮（暂停时列车与到站计时同时冻结） |
| 速度调节 | 滑块 0.2× – 2.5× |
| 白天 / 夜晚 | 「夜晚 / 傍晚」按钮，平滑过渡；夜晚路灯、车站与车窗发光，车头亮灯 |
| 复位 | 「复位」按钮恢复初始机位、列车位置与速度 |

## 场景内容

- 闭合环线轨道（Catmull-Rom 样条，弧线长参数化）：道砟带、实例化轨枕、双钢轨
- 河流横贯沙盘，铁路经两座板梁桥跨河（桥墩、桥台、随曲线分段的梁体）
- 车站：站台、雨棚站房（"溪口站"站牌）、长椅、站台灯
- 镇区：教堂、三间带雨篷招牌的商铺、民居群、南区农舍
- 道路网联系车站与街区，含一处道口（铺面 + 道口标志）
- 北岸：树林、两间小屋、码头栈桥与小船
- 树木为实例化渲染（松树 / 阔叶树，种子随机分布并避让轨道、道路、建筑）
- 草地、木纹、水面纹理均为程序化 Canvas 贴图

## 实现要点

- **列车运动**：轨道为闭合 Catmull-Rom 曲线的弧长参数化采样表；每节车厢独立取前后两个转向架弧长位置，以两点中点定位、连线定向，因此过弯时保持真实间距与朝向，而非整列刚体旋转。
- **进站停靠**：车头进入制动区后按距离幂次减速，恰好停靠在站台中点，停站约 2 秒后平稳驶出；驶出制动区前不会重复触发停靠。
- **昼夜过渡**：傍晚暖阳（长投影）与夜晚月光之间做参数插值，窗户 / 路灯 / 车灯的自发光与光晕同步淡入。
