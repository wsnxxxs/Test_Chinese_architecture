# 桌面微缩铁路小镇（Three.js）

一个可运行的桌面微缩铁路小镇沙盘：带厚度和木框的展示底座上，闭合铁路环绕一座小镇，
包含车站、坡屋顶建筑群、河流与两座铁路桥、公路桥、道路网、树木、路灯与广场喷泉。
一列「车头 + 两节车厢」的火车沿闭合轨道连续运行，每节车厢独立沿轨迹取点，
过弯时保持各自的位置、间距与朝向。默认是带暖色阳光与阴影的傍晚，可切换到夜晚。

## 环境要求

- Node.js 18 或更高版本

## 安装与启动

```bash
npm install
npm run dev
```

启动后打开终端中提示的地址（默认 <http://localhost:5173>），
页面加载完成即可看到完整沙盘与正在运行的列车。

## 构建与预览

```bash
npm run build      # 产物输出到 dist/
npm run preview    # 本地预览构建结果
```

## 操作说明

| 控件 | 作用 |
| ---- | ---- |
| 运行 / 暂停 | 暂停或恢复列车；暂停时车厢与到站计时一起冻结 |
| 速度滑块 | 0.25× – 2.00× 调节车速 |
| 复位 | 恢复初始机位、列车初始位置与 1.00× 速度，并继续运行 |
| 白天 / 夜晚 | 切换光照；夜晚时车站、路灯与部分窗户发光，场景仍保持可见 |
| 鼠标拖拽 / 滚轮 / 右键 | 旋转视角 / 缩放 / 平移（OrbitControls） |

列车每次抵达车站会停留约 2 秒后自动继续运行。

## 技术要点

- Three.js（r160）+ Vite，无后端。
- 轨道由闭合 CatmullRom 曲线生成：道砟为压扁管体，轨枕用 InstancedMesh，
  两根钢轨为沿曲线法线偏移的 TubeGeometry。
- 列车运动：以弧长参数驱动，车头弧长为 `s`，第 i 节车厢取 `s - i × 间距`，
  分别调用 `curve.getPointAt / getTangentAt` 定位与定向，不做刚体整体旋转。
- 到站检测：以车站所在弧长为停车点，越过即停车并启动停站计时。
- 手工模型质感：`flatShading` + 高粗糙度材质、柔和调色板、暖色平行光投影。
