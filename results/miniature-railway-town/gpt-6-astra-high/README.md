# 松溪镇 · The Little Railway

使用 Three.js 和 Vite 构建的桌面微缩铁路沙盘。无后端，无需模型文件，打开后即可看见完整沙盘与运行中的列车。

## 安装与启动

建议使用 Node.js 22.12+。

```bash
npm install
npm run dev
```

访问终端显示的本地地址。默认端口被占用时 Vite 会使用下一个可用端口。也可以指定端口：

```bash
npm run dev -- --port 5187
```

## 构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，可以部署到静态网站服务器。页面需要支持 WebGL 的现代浏览器。

## 操作

- 拖动沙盘旋转视角，滚轮或双指缩放。
- 左下播放按钮运行 / 暂停列车，也可在未聚焦控件时按空格。
- 速度滑块调整为 0.25×–2×。
- 列车每次抵达松溪站停靠 2 秒。暂停同时冻结车厢位置与停站计时；速度不会改变停站时长。
- “暖阳 / 夜色”切换光照。夜间窗户、车站、路灯和列车灯光亮起。
- “复位”或 R 键恢复固定的初始机位、列车位置、1× 速度、运行状态和暖阳模式。
- 页面右上角问号提供操作说明。

## 场景与实现

木质包边底座承载草地、小镇建筑、溪流和环线铁路。两座铁路桥跨越溪流；独立人行桥连接河边住宅与镇中心。车站、面包店、邮局、咖啡馆、住宅、钟楼、广场与步道形成聚落，辅以菜地、围栏、长椅、路灯和模型人物。

- `src/scene.js`：程序化几何、纹理、光照、相机和场景渲染。木纹和草地纹理在本地画布生成；静态无纹理模型按材质合批。使用阴影贴图、像素比上限和有限数量的局部光源。
- `src/simulation.js`：按真实弧长参数化的闭合跑道。车头和两节车厢分别采样位置与切线，保持固定沿轨间距。绝对行程触发到站，防止站点重复触发或高速跳过。
- `src/main.js`：动画循环、状态显示及控件。每帧采用时间步长，页面恢复时不补跑后台时间。
- `src/style.css`：展览式页面与响应式控件布局。

所有 3D 资产都由代码生成。页面字体可通过 Google Fonts 加载；网络不可用时自动使用本地字体，不影响沙盘功能。
