# 云岚宫阙 · Voxel Sanctuary

使用 Three.js 构建的纯前端体素风格中国古典建筑群。场景包含太和正殿、东西配殿、后寝静堂、朱雀山门，以及成对钟鼓楼；中轴御道、石板庭院、围墙、石狮、宫灯和庭园树木共同组成完整宫城。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可进入场景。生产构建与预览：

```bash
npm run build
npm run preview
```

拖动场景可环视建筑，滚轮可缩放；右下角按钮用于重置视角或暂停/继续自动环游。页面加载后会自动显示整体庭院全貌。
