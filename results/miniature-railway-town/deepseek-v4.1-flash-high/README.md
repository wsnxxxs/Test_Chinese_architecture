# 桌面微缩铁路小镇 · Miniature Railway Town

基于 **Three.js** 的正交等距视角桌面沙盘：木质底座 + 边框，闭合铁路环绕一座可辨认的微缩小镇，一列 1 车头 + 2 车厢的列车沿轨独立行驶、到站停留约 2 秒，支持运行/暂停、调速、复位与昼夜切换。全部几何与贴图均由代码程序化生成，无任何外部模型/图片资源。

---

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| Node.js | `^20.19.0` 或 `>=22.12.0`（Vite 8 的 engines 要求；开发机实测 v24.18.1） |
| 浏览器 | 支持 WebGL2 的现代桌面浏览器（实测 Chromium / ANGLE·D3D11·GPU 加速） |
| 依赖 | `three@0.186.1`、`vite@8.3.1`（`npm install` 自动安装） |

## 2. 安装与启动

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器，默认 http://localhost:5173/
npm run build      # 生产构建，产物输出到 dist/
npm run preview    # 本地预览构建产物，默认 http://localhost:4173/
```

打开页面即可看到完整沙盘（含边框底座）与正在运行的列车，默认时段为**傍晚**、速度倍率 **×1**。

## 3. 使用方式

| 操作 | 方式 |
| --- | --- |
| 旋转视角 | 鼠标左键拖拽（轨道式旋转，始终环绕沙盘中心） |
| 缩放 | 鼠标滚轮（正交缩放 0.42×–3.2×） |
| 运行 / 暂停 | 面板「暂停 / 继续」按钮，或键盘 <kbd>空格</kbd> |
| 复位 | 面板「复位」按钮，或键盘 <kbd>R</kbd> |
| 调速 | 面板「速度倍率」滑块：0.25×–2.5×，即 1.375–13.75 单位/秒；面板实时显示倍率与每秒单位数 |
| 昼夜切换 | 面板「时段」：白天 / 傍晚 / 夜晚（三档之间为约 1.1 秒的平滑过渡） |

说明：

- **暂停**会同时冻结列车位置与到站计时（停站倒计时也暂停）；水面波动、光照与时间推进继续，画面不会“死掉”。
- **复位**把相机机位、列车位置、速度倍率、时段、暂停状态全部恢复到初始值（相机为确定性恢复，非近似）。
- 不允许平移视图（`enablePan = false`），避免把沙盘推出画面；窗口尺寸变化时自动重算取景，保留当前机位与缩放。
- 页面内提供只读诊断句柄 `window.__railway`：`state()`（运行状态）/ `camera()`（机位）/ `audit()`（场景统计、NaN/空几何/缺失材质检查），便于排查问题。

## 4. 场景构成

- **底座**：44 × 33 木纹底板 + 1.3 宽边框（含倒角与顶面压条），南侧名牌；底板有厚度与内衬封口，看不见空腔。
- **轨道**：闭合曲线全长 **92.13 单位**（CatmullRom 闭合、centripetal 参数化），含道砟（过桥处断开）、184 根轨枕、两条连续钢轨。
- **跨河结构**：河道自南向北斜穿沙盘，轨道与河岸带只相交 **2 段**，分别由**北侧钢桁架桥**与**南侧双拱石桥**跨越（拱券、栏板、八字挡墙、桥台落至河床以下）；另有 3 座公路桥（含分水尖桥墩）。
- **小镇**：车站（雨棚、站台红边与警戒线、站牌、挂钟、长椅、行李车、花箱）、联排住宅、独立住宅、教堂与钟楼、市政厅、磨坊（含水塘）、水塔、谷仓、商铺、仓库等；道路网 9 条（路面 + 人行道 + 路缘 + 标线）串联车站与各街区。
- **配景**：152 棵树（6 种树冠 + 灌木）、22 段绿篱、25 盏铸铁路灯、栅栏、喷泉、长椅、告示板/指路牌、货运仓库木箱酒桶、草垛、菜畦、河岸小码头、臂板信号机、电报杆。
- **列车**：1 节蒸汽机车 + 2 节客车，**逐节沿轨道独立定位**（各自取弧长、各自取切向朝向），非刚体；机车轮系与连杆按行进相位驱动。

## 5. 技术要点

- **正交等距相机**：按底座投影包围盒自适应取景（多宽高比一致性由实测覆盖）。
- **合批与实例化**：自写几何合批（geometry bucket）+ `InstancedMesh`（树木、路灯、轨枕、车轮、栅栏柱等），全场景约 **321 draw call / 16.6 万三角面 / 23 张纹理**。
- **程序化贴图**：木纹、草地、碎石、石墙、砖、瓦、木瓦、玻璃、水面法线等全部由 canvas 绘制；纹理生成与所有随机布置均使用确定性种子（`mulberry32`），刷新页面结果一致。
- **光照**：平行光（2048² 阴影贴图，按光向拟合正交阴影相机）+ 半球光 + 环境光 + 由天空渐变烘焙的 PMREM 环境贴图 + 顶点色天空穹顶；时段切换对颜色与标量逐项插值，方位角走最短弧。
- **夜灯**：站台吊灯、路灯、亮窗、车灯采用自发光材质；路灯另有最多 8 盏点光源（按优先级取前 8，避免超出 GPU 限制）。
- **列车运动**：弧长参数化 + 固定子步积分（≤ 1/120 s，每帧上限 1/20 s 防止切页后跳跃），到站状态机 `run → braking → dwell(2 s) → depart → run`，一圈只停一次；停车点精确落在车站弧长上。

## 7. 验证记录（如实说明）

**实测环境**：Windows 10.0.26200 / Node v24.18.1 / `npm run build` + `vite preview` / Chromium 无头模式 1440×900（ANGLE D3D11，NVIDIA RTX 5060 Laptop，GPU 加速）/ 浏览器自动化（真实鼠标拖拽、滚轮、键盘、按钮点击）。

### 已实测通过（端到端）

1. **构建**：`npx vite build` 通过，23 个模块，产物 `dist/assets/index-*.js` 734.91 kB（gzip 197.73 kB）。
2. **运行无报错**：加载后 `console` 条目 0 条、页面错误 0 条；加载遮罩在首帧后移除；默认状态 `{paused:false, speedMultiplier:1, speed:5.5, mode:'evening'}`。
3. **首屏取景**：含边框底座 8 角点投影 maxNDC = **0.93**（≤ 1 即完整可见），在 1440×900、900×1200、1920×1080、390×844、2560×1080 五种比例下均成立。
4. **列车运行**：巡航速率实测 0.0597 弧长/秒（= 5.5 单位/秒 ÷ 92.13，比值 0.993–1.000）；单圈约 18.4 秒（含停站）。
5. **到站停靠**：停点弧长恒为 **0.627083**（与车站契约停点一致）；停留时长实测 **2.001–2.008 秒**（4 ms 采样精度）；每圈仅停靠一次；停站期间面板状态显示“停靠站台”。
6. **暂停语义**：暂停时列车弧长与停站计时**完全冻结**（暂停 3.5 秒后 `arc` 与 `stopped` 均未变化），而累计时间与水面/光照仍在推进（实测 elapsed 1.506 s / 帧 dt > 0）；恢复后从冻结值连续继续，无跳变。
7. **调速**：滑块拉到 2.5×，`speed` 变为 13.75 单位/秒，面板同步显示 `×2.50 / 13.75 单位/秒`，实测速率比 0.993。
8. **复位确定性**：制造扰动（旋转 + 缩放 1.16× + 2.5× 速度 + 夜晚 + 暂停）后按复位，相机 `position/zoom/target` 与初始值偏差 **0.0e+0**，速度倍率、时段、暂停状态全部回到初始。
9. **昼夜切换**：三档按钮切换生效（`mode` 与按钮高亮同步），白天画面明亮清晰、夜晚窗户/路灯/车灯发光且场景仍可辨认。
10. **场景自检**：0 个 NaN 顶点几何、0 个空网格、0 个缺失材质；1 个默认材质（天空穹顶，预期行为）；183 网格 / 222 对象 / 166,100 三角面 / 321 draw call / 23 纹理 / 20 程序。
11. **轨道与水道关系**：轨道进入河岸带的弧段只有 2 段（u≈0.0905–0.158 与 0.5105–0.5795），分别落在桁架桥（u 0.0879–0.1596）与石拱桥（u 0.5075–0.5813）区间内，一一对应。
12. **可视化抽查**：列车在紧弯处（曲线最小曲率半径实测 **3.77**，位置 (11.39, −10.12) 一带）截图确认——三节车各自贴合轨道切向，无刚体整体旋转；机车在石拱桥上、两节车厢在弯道上的形态与轨道走向一致。

### 模块级自检（由各模块作者用临时离线脚本完成，脚本未纳入交付）

- 列车：车轮最低点全程 = 0.440000（轨顶高度）；车体最小间距 0.081 / 0.138 单位（分离轴测量，无穿插）；朝向连续（相邻采样最大变化 1.16°）；连杆相位与动轮误差 6.9e-9；重置与相同调用序列逐位可复现。
- 车站：站台顶面 y = 0.55、站台最外沿 z = 9.55（不进入列车包络）；站牌、钟面指针、6 个夜灯锚点参数一致。
- 建筑：50 个合并网格全部使用共享材质（无默认材质回退）、0 退化三角面；每个地块到轨道的最小距离 ≥ 1.391（限值 1.35）。
- 地形 / 轨道 / 配景：河床最低 −1.410（水面 −0.620）、道砟不越桥、桁架与木桥面底部高于水面、公路桥墩落至 −1.40；配景 0 个实例落入轨道禁入带。

### 未验证 / 如实说明

- 仅在 **Windows + Chromium（无头、GPU 加速）** 环境实测；未在 macOS / Linux、Firefox / Safari、真实移动设备上验证。
- 帧率实测 3.15 ms/帧（约 317 fps，1440×900，最大 6.1 ms）**仅代表上述环境**，实际帧率取决于用户设备与窗口尺寸。
- 项目**未附带自动化测试套件**：上述结论来自构建、浏览器端到端实测与各模块的临时离线校验脚本，脚本按“不留下无用产物”的原则已删除，因此无法用一条命令重跑这些断言。
- 太阳光晕精灵仅在镜头几乎正对太阳时进入视锥（正交视锥范围小），默认视角看不到它，属于预期表现。
