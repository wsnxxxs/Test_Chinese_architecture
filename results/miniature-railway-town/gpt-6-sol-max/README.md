# Willowmere Railway

一个可直接运行的 Three.js 桌面微缩铁路小镇。木制展示底座上有闭合铁路、三节列车、柳溪车站、住宅、教堂、磨坊、农舍、河流和跨河桥梁。页面打开后列车会自动运行，默认是有暖色阳光和阴影的傍晚。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址。构建生产版本：

```bash
npm run build
npm run preview
```

## 使用方式

- 拖动沙盘旋转视角，使用滚轮或触控板缩放；触屏上可拖动旋转、双指缩放。
- **运行／暂停**控制列车。暂停时列车运动与车站停靠倒计时都会暂停。
- **速度**可在 0.5× 到 2.0× 之间调节；每次进站停留约两秒。
- **夜晚／白天**切换场景照明。夜晚车站、路灯与部分窗户发光。
- **复位**恢复初始机位、列车位置、1.0× 速度、运行状态和傍晚光照。

铁路线路用直线和圆弧组成闭合环线，车头及两节车厢各自按线路里程和切线更新位置与朝向。场景在浏览器内生成，无后端和外部素材请求。

## 验证

已执行 `npm run build`，构建成功。也已在浏览器打开开发服务器，确认首屏沙盘可渲染、进站状态会显示。另以 Node 检查了环线首尾、停站计时、暂停和复位逻辑。浏览器中的全部交互流程尚未逐项完成自动化验证。
