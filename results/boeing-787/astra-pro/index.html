MODEL NOTES / 787–9

看见结构，也看见运动。

左键或单指拖动旋转，滚轮或双指缩放，右键拖动平移。双击模型可聚焦部位。1–6 切换预设，R 复位镜头，G 收放起落架，F 启停风扇。

模型与机构

1 个场景单位对应 1 米。机身采用连续截面放样，翼面采用带后掠、渐缩、上反角与扭转的翼型曲面。GEnx 风格发动机包含 18 片扭转风扇叶片、厚唇口、静子、旁通涵道、核心机与锯齿形尾缘。

客舱与驾驶舱玻璃使用具有透射、折射与环境反射的物理材质；蒙皮开口后方设有内部墙面、地板、座椅和驾驶舱暗部。收放机构包含转轴、折叠撑杆及分阶段舱门动作。左右主起落架各为四轮小车，前起落架为双轮。

展示边界

这是程序化视觉近似，不是 Boeing 官方模型、工业 CAD、飞行模拟或维修培训工具。机构行程与干涉余量经过可视化设计，未依据完整制造图纸。收起起落架时机体保持固定，避免把机构演示误解为实际滑行或飞行。

尺寸参考：Boeing 787 官方规格。风扇构型参考：GE Aerospace GEnx。渲染：Three.js r170 与官方 OrbitControls。无外部模型、图片、字体或 HDR 资源；涂装、遮罩及环境反射均在本文件运行时生成。

运行需要支持 WebGL 2 与 import maps 的现代浏览器，以及可访问 jsDelivr 的网络。已完成 JavaScript 语法、DOM 引用和机构端点的静态检查；制作环境未能加载 CDN 依赖，未完成实际三维渲染与帧率验证。低性能设备可选择“性能优先”。实际帧率取决于设备与视角。
