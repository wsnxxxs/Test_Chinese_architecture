# 桌面微缩铁路小镇 · Miniature Railway Town

一个用 **Three.js** 制作的桌面微缩铁路沙盘：木质展示底座上是闭合的环形铁路、一座带站台与货场的小站、沿河聚落、两座跨河铁路桥、道路与路灯、树木与田野，以及一列由「一节机车 + 两节客车」组成、沿轨道连续运行的火车。

整体走「手工模型／实体沙盘」的质感路线（程序化木纹、草地、石材、瓦片、水面贴图 + 柔和的圆角与不规则细节），不使用体素风格。

---

## 1. 环境要求

- Node.js ≥ 18（开发时使用 Node 24 验证）
- npm（或 pnpm / yarn 均可）
- 支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox / Safari）
- 无需后端、无需外部素材：所有贴图在运行时用 Canvas 程序化生成

## 2. 安装与启动

```bash
# 1) 安装依赖
npm install

# 2) 开发模式（默认 http://127.0.0.1:5173）
npm run dev

# 3) 生产构建（输出到 dist/）
npm run build

# 4) 本地预览构建产物（默认 http://127.0.0.1:4173）
npm run preview
```

打开页面即可看到完整的沙盘与正在运行的列车，无需任何额外操作。

> 提示：构建产物使用 ES Module，请通过 `npm run preview` 或任意静态服务器访问 `dist/`，不要直接用 `file://` 打开 `index.html`。

## 3. 使用方式

| 操作 | 说明 |
| --- | --- |
| 拖拽左键 | 旋转视角 |
| 滚轮 | 缩放（38 ~ 430） |
| 拖拽右键 / 双指 | 平移视角 |
| **运行 / 暂停** 按钮（或 `空格`） | 暂停时列车、到站计时、水面波纹、水车全部停止 |
| **复位** 按钮（或 `R`） | 恢复初始机位、列车初始位置与默认速度，并解除暂停 |
| **速度** 滑杆 | 2 ~ 26 单位/秒，默认 11 |
| **切换到夜晚 / 白天**（或 `N`） | 昼夜切换（约 0.8 秒过渡） |

面板右下角的状态胶囊会显示「运行中 / 到站停靠 / 已暂停」。

## 4. 沙盘内容

- **展示底座**：104 × 72 的木质台面，带厚底板、 moulding 边框、四只车脚与正面黄铜铭牌；底座下方是桌面。
- **铁路**：一条闭合单线环线（约 220 单位周长，含长短直线与缓和曲线），枕木、钢轨与道砟沿曲线连续生成，环线整体连续无断口。
- **桥梁**：环线两次跨河 —— 北侧为**钢板梁桥**（板梁、加劲肋、纵横联结系、栏杆、河中石墩），南侧为**石拱桥**（拱券、胸墙、桥面、栏杆）。桥梁跨度由程序自动检测河道范围后生成，与水面、护坡自然衔接。
- **车站**：站台（带压顶石与端部坡道）、站房、站棚与雨棚柱、长椅、站台灯、水塔、信号机、货场与尽头式岔线（含车挡与货车）、电报杆与电线。
- **小镇**：镇公所（带钟楼柱廊）、教堂（钟塔 + 尖顶 + 扶壁 + 彩色玻璃）、店铺排屋、客栈、学校式公寓、散布的住宅（沿道路两侧程序化排布，带烟囱、老虎窗、凸窗、门廊、栅栏与树篱）。
- **河流与西岸**：蜿蜒河道、沙质河床、护坡、水车磨坊（水轮持续转动）、谷仓、干草垛、果园、水井与成排的农田。
- **道路**：主街（沥青）、北巷 / 货场支路 / 磨坊巷 / 磨坊小径（碎石），自动与车站、货场、居民区、磨坊相连；跨河处生成石拱桥或木栈桥；与铁路相交处生成**平交道口**（木铺面板、铁轨间铺板、道口标志）。
- **环境**：草地与地形起伏、河岸树丛、西北角针叶林、灌木与树篱、路灯（夜间发光）、以及夜间亮起的部分窗户。

## 5. 操作与机制实现要点

- **每节车厢独立沿轨迹行驶**：不对整列车做刚体旋转。每节车分别按弧长参数取「前转向架—后转向架」两个轨迹点，用两点连线决定车体位置与朝向，因此在弯道上每节车的角度各不相同、间距稳定。
- **到站停靠**：机车（列车中心）抵达站台中心对应的弧长位置时，整列车停靠约 2 秒后继续运行；停靠计时与全局暂停联动。
- **昼夜**：两套预设（傍晚暖阳 / 月夜）之间对光照颜色与强度、半球光、环境贴图、雾、曝光做插值过渡；夜间点亮窗户（约半数窗户）、站台灯与路灯的自发光材质，并在重要灯位放置点光源 + 加法混合光晕精灵。
- **性能**：全部静态几何按材质合并（约 37k 三角形 → 约 230 次绘制调用），树木与灌木使用实例化的低面数几何体，阴影贴图 2048²，像素比上限 2。

```
shots/                  作品展示截图
```

## 7. 运行说明

未验证 / 需说明的部分：

- 原交付的无头环境使用 **软件渲染（SwiftShader）**，帧率仅数 FPS，是该环境的限制；**未在真实 GPU 上测量帧率**。场景规模（约 96k 三角形、233 draw call、单张 2048² 阴影贴图）按桌面独显/核显预期可流畅运行，但这一点未经实测。
- 未在 Firefox / Safari 上实测，仅在 Chrome（Edge 同内核）验证。
- 未做移动端触控实测（OrbitControls 支持触控，面板为响应式布局）。
- 复位不会改变当前「白天 / 夜晚」选择（按需求只要求恢复初始机位、列车位置与速度）；这一点为有意设计。

## 8. 可调参数速查

| 位置 | 参数 | 作用 |
| --- | --- | --- |
| `src/world/layout.js` | `TRACK_POINTS` / `RIVER_POINTS` | 环线与河道形状（桥梁、道砟、道路让位均据此自动推导） |
| `src/world/layout.js` | `WATER` | 水位、河床深度、河道宽度与护坡宽度 |
| `src/world/layout.js` | `ROAD_DEFS` | 道路走向、宽度、铺面与桥型（`bridge: 'timber'`） |
| `src/world/layout.js` | `COLORS` | 墙面粉刷、屋顶、植被配色 |
| `src/world/train.js` | `CAR_SPACING` / `DWELL_TIME` | 车厢间距与停站时长 |
| `src/world/lighting.js` | `DAY` / `NIGHT` | 两套光照与天空预设 |
| `src/main.js` | `HOME` / `DEFAULT_SPEED` | 初始机位与默认速度（复位即回到这里） |
