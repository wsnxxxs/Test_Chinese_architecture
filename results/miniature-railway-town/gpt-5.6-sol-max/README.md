# 溪谷镇 · Three.js 桌面微缩铁路

一个可直接运行的桌面微缩铁路沙盘。场景采用近似等距视角，包含有厚度的胡桃木展示底座、闭合双轨、两座铁路桥、河流、道路桥、车站、镇中心建筑、路灯、树木和一列由车头与两节独立车厢组成的列车。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

终端会显示本地访问地址，通常为 `http://localhost:5173`。

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 鼠标左键拖拽：旋转视角
- 滚轮或触控板：缩放
- “运行／暂停”：控制整列火车；暂停时到站停留计时也会冻结
- “车速”：在 `0.5×` 到 `1.8×` 之间调整
- “白天／夜晚”：切换环境灯光，夜晚会点亮站房、车窗与路灯
- “复位”：恢复初始机位、白天模式、列车位置、运行状态和 `1.0×` 速度
- 键盘 `Space`：运行／暂停；`R`：复位

列车沿同一条闭合轨迹按弧长运动。车头与两节车厢分别取样各自的位置和切线，因此转弯时能保持独立朝向和稳定间距。车头抵达溪谷站后会停留约两秒，再继续下一圈。

## 技术说明

- Vite + 原生 JavaScript + Three.js
- 使用正交相机与 OrbitControls 实现等距感视角
- 使用程序化材质、圆角几何体和低多边形手工模型造型，不依赖外部模型或贴图资源
- 阴影使用 PCF Soft Shadow Map，并限制设备像素比以兼顾清晰度和运行流畅度
