## 卡片模型预览

- 压缩包的九份 `.sbox` 放在 `site/assets/scenes/chinese-architecture/`，按上述作品 ID 对应。文件保留原建筑顶点、材质、体素实例及颜色；来源中的离线处理记录见下文。
- 其他作品复用沙盘的场景提取方式，从专用构建副本读取原模型。铁路与键盘也生成专用提取副本。
- 一个共享 WebGL 渲染器绘制真实场景，图像交给各卡片的 canvas 显示。卡片原有尺寸、圆角、按钮和页面布局保留；鼠标移动时重新渲染对应模型。
- 只加载视口附近的作品；静止时不持续重绘。离开题目页会释放场景与 GPU；截图对照、提示词、截图大图和完整原作预览不运行卡片渲染。
- 压缩包的作品统一居中、缩放、使用展厅光照和薄底座。现有作品的卡片沿用统一沙盘光照与远景简化，点击后打开完整原始实现。
- 原有截图对照、条件切换与图片放大布局不改变，保留所有旧截图。新增作品保留随附的统一模型图作为作者预览，并补充本地原作首屏（1440×900）与手机（390×844）截图用于截图对照。

## 压缩包建模处理来源

压缩包 `SOURCES.md` 记录：场景使用原作品的建筑生成函数、布局和材质；Astra 略去天空、远景与界面；Fable 略去远山和云层；Gemini、Kimi、DeepSeek、Qwen 复用建筑布局及体素数据；GLM 略去远山并裁去外围地面；Seed 执行原有场景布局；MiniMax 略去远山、缩小外围草地并剔除地下装饰。合并适用的材质和几何，保留实例颜色，剔除适用体素的内部面。卡片预览没有重新设计建筑。

品牌标识继续使用项目已有资源，来源见 `site/assets/brands/README.md`。Three.js 采用 MIT 许可，许可见依赖包。压缩包未提供这些作品的独立许可声明。
