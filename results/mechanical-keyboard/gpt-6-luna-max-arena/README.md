# NOVA 68 键盘工作室

一个使用 React、Vite 和 Three.js 构建的原创机械键盘 3D 展示与配置页面。无需后端服务。

## 安装与启动

```bash
npm install
npm run dev
```

在终端输出的本地地址打开页面即可。生产构建：

```bash
npm run build
```

## 使用方式

- 选择三种外壳颜色与三种键帽主题，68 键 3D 预览和配置摘要会同步更新。
- 在预览区拖动旋转，使用滚轮缩放；右上角控件可旋转、缩放和复位视角。
- 点击“拆解结构”查看键帽、定位板与底壳分层，再次点击即可平滑组装。
- 开启“键盘体验”后，可按 A–Z 或空格，或直接点击预览中的字母键和空格键，体验键帽下压与回弹。
- 配置会保存在浏览器的 `localStorage` 中；“恢复默认配置”只移除本项目使用的 `nova68-studio-config-v1` 配置项。

## 技术说明

3D 键盘由 Three.js 在浏览器中实时绘制，包含 68 枚带字符的键帽、机械轴体、金属定位板、铝合金底壳、底脚和前置接口。页面控件是常规 HTML/React 元素，不会被绘制到 Canvas 中。
