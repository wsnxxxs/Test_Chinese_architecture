# Evergreen Junction

一个使用 Three.js 搭建的桌面微缩铁路小镇。场景包含有厚度的木质展示底座、闭合环线、两座跨河桥、车站、道路、建筑、树木和傍晚／夜晚灯光。

## 安装与启动

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 使用

- 鼠标左键拖拽旋转视角，滚轮缩放，右键拖拽平移。
- `暂停列车`／`继续运行` 控制列车和到站停留计时。
- 速度滑杆改变列车巡航速度。
- `切换夜晚` 打开车站、路灯和窗户灯光。
- `复位` 恢复默认机位、运行状态、列车位置、速度和暖色傍晚光线。

列车由一个车头和两节独立车厢组成，按照各自沿轨迹的距离更新位置与朝向；抵达车站后会停留约两秒再继续行驶。
