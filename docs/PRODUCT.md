## 定位与范围

「同题异答」是一个静态前端作品档案：同一份提示词交给不同模型，收录它们生成的可运行前端项目，在同一站点里在线运行、并排对比、查看统一截图、提示词与源码。

- 部署：GitHub Pages 纯静态站点（https://wsnxxxs.github.io/same-prompt-gallery/），无后端、无账号、无数据上报；偏好只存浏览器本地。
- 界面语言：仅简体中文。
- 当前规模：5 道题目 / 81 份作品 / 32 个注册模型 / 15 家厂商。

## 内容与收录口径

- **作品**＝一个模型在某一推理档位下对某道题的一次交付。同一模型的不同档位、不同来源（如 Arena）分别收录为不同作品；模型数量按 `gallery.json` 注册表计，不按作品计。
- **原作不改**：在线预览、新窗口打开、原作展厅运行的都是作品自身构建产物的原样副本；站点不为统一展示修改作品的布局、画质或交互。确需最小兼容修复时在作品 README 说明。
- **统一截图**：每份作品必须有两张真实首屏——桌面 1440×900、手机 390×844（触屏、竖屏），全新浏览器上下文、浅色系统主题、默认状态、不做任何操作。截图只证明首屏效果，不代表提示词全部要求已验证。
- **卡片小模型**：每份作品必须有预生成的 `.sbox` 模型包，只用于题目页卡片的轻量三维预览，不是原作的替代品。
- **厂商身份**：只采用可核实的归属；未确认的保留 `vendorNote`，在首页模型索引中以标注显示（当前为 Space-bunny「厂商待确认」）。
- **提示词**：题目页展示的是题目 `PROMPT.md` 原文；原文缺失时明示「待补充」，不代写。

## 数据模型

主站只读取构建生成的 `data.json`，由三类源数据汇总：

| 源 | 关键字段 | 产品含义 |
| --- | --- | --- |
| `gallery.json` → `models[]` | `id`、`name`、`vendor`、`logo`、`brandName`、`brandUrl`、`vendorNote?` | 模型与厂商注册表；Logo 点击跳转厂商官网 |
| `tasks/<task>/task.json` | `title`、`summary`、`date`、`order`、`tags`、`conditions[]`、`sandtable?`、`sceneProfile?` | 题目；按 `date` 再按 `order` 排序；`conditions` 定义截图条件（`first`、`mobile`）；`sandtable` 开启沙盘、展厅与多选，`sceneProfile` 决定卡片模型的取景规则 |
| `results/manifest.json` | `id`、`task?`、`model`、`modelId?`、`effort?`、`sourceLabel?`、`title`、`description`、`cover`、`addedAt`、`guide?`、`captureNote?` | 作品；`effort` 显示为档位徽标，`sourceLabel` 显示为来源徽标，`addedAt` 决定默认排序，`guide` 生成在线预览的操作指南 |

`guide` 结构：`presets[]`（`label` + URL `query`，用于「快速跳转」）、`sections[]`（`title` + `[按键, 说明]` 列表）、`tips[]`（看点）。

## 用户路径

全部路由基于 URL hash，任何状态都可以通过链接分享或刷新恢复。

### 首页 `#/`

- 顶部统计：题目、厂商、模型、作品四个计数。
- **题目列表**：按发布时间排列；每张卡片含最多 5 张作品封面拼图、编号与日期、摘要、标签、作品/模型/厂商计数。操作按钮为「浏览作品」，建筑题另有「三维沙盘」，其他题目在作品 ≥2 时提供「并排对比」（默认取前两件）。
- **模型索引**：可折叠，按厂商字母序分组；每个模型列出其全部作品（带档位与来源徽标），点击直接进入在线预览；无作品的模型显示「暂无作品」。

### 题目页 `#/任务id`

顶部为题目信息与作品/模型/厂商计数，下方子导航切换三个面板，面板写入 hash（`#/<task>#shots`、`#/<task>#prompt`）：

- **作品**（默认）
  - 厂商筛选芯片（含各厂商作品数）；排序三选一：加入时间（最新在前，默认）/ 模型厂商 A–Z / 模型名字 A–Z，排序选择本地记忆。
  - 卡片预览二选一：「截图」（默认，统一桌面首屏）或「小模型」（桌面端可随鼠标轻转；触屏与减少动态效果偏好下不转动；离屏与静止时停止绘制），选择本地记忆。
  - 卡片提供在线预览、作者截图灯箱（有作者截图时）、源码链接（GitHub 目录）。
  - 对比选择：作品 ≥2 时每张卡片可勾选「对比」，底部出现对比栏。普通题目最多保留最近两件，选满两件可「并排对比」；建筑题可多选，两件时可并排对比，任意数量可「进入沙盘」。
- **截图对照**：按截图条件（桌面首屏 / 手机界面预览）切换网格，手机条件以竖屏比例排布；显示条件说明与各作品的 `captureNote`，并提示自动截图可能使用软件渲染。点开大图后 ←/→ 换作品、↑/↓ 换条件。
- **提示词**：原文展示，可一键复制或跳转 GitHub。

### 作品预览与对比 `#/任务id/作品id`、`#/任务id/A/vs/B`

- 全屏 iframe 运行原作，载入时以封面为底显示加载层（iframe `load` 后或 20 秒后隐藏）。
- 顶栏：返回题目、上一件/下一件、作品下拉选择；工具按钮为指南、并排、新窗口打开、全屏、主题切换，建筑题另有「沙盘」（把当前一栏或两栏作品带入三维沙盘）。
- **操作指南**抽屉：作品摘要、快速跳转预设（切换 URL 参数重载该栏）、原作操作说明、看点、本站快捷键、源码与项目说明链接。宽屏（≥1100px）记忆开关状态，窄屏按 Esc 收起。
- **并排对比**：两栏各有独立下拉选择与关闭按钮，点击或焦点进入某栏即设为当前栏，上一件/下一件与指南作用于当前栏；切换一栏不会重载另一栏。窄屏上下堆叠。
- 本站快捷键：←/→ 切换作品，G 指南，S 并排，F 全屏，R 重载当前栏。焦点进入原作 iframe 后键盘归原作所有，点击顶栏恢复。
- 旧地址 `/<task>/<id>/` 保留跳转页，自动转到作品当前路径。

### 三维沙盘与原作展厅（仅中式建筑题）

两种模式共用顶栏，可互相切换；已选作品写入 URL（`#/chinese-architecture/sandtable/<id,id…>`、`…/exhibition/<id,id…>`）。左侧作品库支持搜索、厂商筛选、清空已选。

- **三维沙盘**：从专用构建副本提取各作品场景，摆在同一展台，统一相机、固定光照、随主题变化的天空与地景。支持拖动旋转、右键平移、滚轮缩放，斜视/俯视切换、总览、聚焦单件，并可「进入原作」。只用于比较布局与结构，光影、动画不代表原作。性能与场景处理见 `docs/sandtable.md`。
- **原作展厅**：把多件完整原作以 iframe 平铺在可平移缩放的画布上，保留原作全部光影、动画与交互；支持总览、缩放、1:1 像素、点击进入操作单件原作与独立打开。

## 界面口径

- 浅色/深色双主题：首次跟随系统，手动切换后本地记忆；未手动选择时随系统实时变化。
- 响应式断点：640 / 860 / 1000 / 1099–1100px；触屏设备始终显示卡片上的「在线预览」「对比」按钮。
- 尊重「减少动态效果」：关闭主题过渡动画与卡片模型跟随鼠标转动。
- 模型展示名 = 注册名 + 档位（如「GPT-6 Sol · High」），档位与来源另以徽标显示。
- 视觉 token 与组件规范见 `docs/DESIGN.md`。

## 当前未实现

以下为代码中不存在的能力，列出以免误以为已有；是否要做见 `docs/IDEAS.md`，不构成待办。

- 站点不对作品打分、排名或给出性能结论；三维沙盘帧率与模型包体积警告都不作为评分。
- 不展示作品的技术栈、源码行数、构建体积等资料（曾有的未展示字段已于 2026-09-27 删除）。
- 三维沙盘、原作展厅、多件对比目前只有中式建筑题开启（其他题目可通过 `task.json` 开关开启，但沙盘场景处理按建筑群设计，未在其他题目上验证）；其他题目只能两件并排。
- 没有跨题目的全站搜索，没有按模型聚合的独立页面（仅首页模型索引）。
- 仅简体中文界面，无多语言。
- Boeing 787 与腾势 Z Racing 两题的提示词原文尚未提供。
