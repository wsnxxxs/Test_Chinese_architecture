# MERIDIAN 65

DeepSeek V4.1 Flash 生成的单文件机械键盘展示与配置页面。Three.js、样式和界面脚本已内联在 `index.html` 中，可直接用浏览器打开。

## 运行与构建

在仓库根目录安装依赖后，可在本目录运行：

```bash
npm run dev
npm run build
npm run preview
```

构建复用仓库的静态复制脚本，原样复制页面到 `dist/index.html`，不重新打包内联代码。

## 使用

拖动旋转键盘、滚轮缩放，使用复位按钮恢复视角。右侧面板提供外壳配色、键帽主题、拆解组装、体验模式、保存配置和恢复默认。
