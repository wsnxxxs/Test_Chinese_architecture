# Third-party notices

## Three.js

This application depends on Three.js version 0.180.0, including OrbitControls,
under the MIT license. Copyright belongs to the Three.js authors.

The dependency is installed from its npm distribution. A local build copies
the original package's LICENSE, unchanged, to `dist/vendor/LICENSE`. The
CDN-backed build loads the pinned distribution from jsDelivr; no Three.js
engine source is embedded in that build directory.

Official resources:

- Project: https://threejs.org/
- Repository: https://github.com/mrdoob/three.js
- License for the pinned release: https://github.com/mrdoob/three.js/blob/r180/LICENSE
- Instancing: https://threejs.org/docs/pages/InstancedMesh.html
- Controls: https://threejs.org/docs/pages/OrbitControls.html

## Artwork, textures and fonts

Buildings and environment objects are generated by this project. No third-party
model or image-texture asset is bundled. Plaques are drawn on an HTML canvas.
CSS and Canvas use system font fallbacks; no font files are included or fetched.

## Diagnostic preview

`docs/geometry-preview.png` is an offline geometry-inspection render produced
using VTK, not a screenshot of this application's Three.js renderer. VTK is
not a dependency of the application and is not included in the distribution.
