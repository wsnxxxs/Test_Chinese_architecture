# DeepSeek V4 Pro · High — 桌面微缩铁路小镇

铁路小镇题目的独立作品，High 为用户明确提供的思考等级。原交付为单个已构建 HTML 文件，内含页面样式、Three.js 场景代码和运行依赖；仓库保留该静态页面，不反向还原源码。

页面展示木质底座上的闭合铁路、小镇、河流、桥梁与三节列车，支持拖拽旋转、滚轮缩放、右键平移，以及暂停、速度、复位和昼夜切换。

## 运行

可直接打开 `index.html`，或在仓库根目录运行：

```bash
npm install
npm run dev --workspace=gallery-miniature-railway-town-deepseek-v4-pro-high
npm run build --workspace=gallery-miniature-railway-town-deepseek-v4-pro-high
```

构建按原样复制页面到 `dist/`。`docs/cover.jpg` 和题目目录中的截图供画廊展示使用。
