# KEPLER 65 交互式键盘配置器

一个原创 65% 紧凑机械键盘的单页产品展示与配置项目。产品模型由 Three.js 实时生成，配置面板、状态反馈与产品说明均使用正常 HTML/CSS 实现。

## 功能

- 64 枚可辨认键帽，包含数字行、字母区、方向键、空格、回车与不同宽度的 Shift
- 键帽、轴体、CNC 定位板、PCB 与铝制底壳的分层 3D 结构
- 鼠标或触控拖拽旋转、滚轮缩放，以及视图旋转、缩放、复位按钮
- 3 种外壳颜色与 3 种键帽主题自由组合，3D 预览与配置摘要实时同步
- 键帽、定位板和底壳平滑拆解/组装；连续快速切换不会累积错误动画
- 键盘体验模式支持实体键盘 A—Z、空格和直接点击 3D 键帽
- 配置保存到浏览器本地，刷新后恢复；恢复默认只删除 `kepler-65-config-v1` 这一项页面配置
- 桌面、平板与手机响应式布局

## 安装与启动

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

Vite 会在终端显示本地访问地址。生产构建：

```bash
npm run build
```

构建输出位于 `dist/`。如需本地预览构建结果：

```bash
npm run preview
```

## 使用方式

1. 在右侧面板选择外壳配色与键帽主题。
2. 点击“拆解结构”查看键帽、轴体、定位板与底壳；再次点击即可组装。
3. 开启“键盘体验模式”，按实体键盘上的 A—Z 或空格，或直接点击 3D 键帽。
4. 拖拽产品旋转视角，使用滚轮或底部工具栏缩放；“复位”返回初始产品角度。
5. 点击“保存此配置”写入本机浏览器；“恢复默认”只清除此项目自己的本地配置。
