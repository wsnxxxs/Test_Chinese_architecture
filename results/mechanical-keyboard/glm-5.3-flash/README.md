# AXIS 68 · 机械键盘交互式产品展示与配置页面

原创紧凑机械键盘「AXIS 68」的产品展示 + 实时配置页面。Three.js 渲染 3D 键盘，原生 HTML/CSS 承载配置界面（未把页面画进 Canvas），无后端、无外部资源依赖（含字体与图标），安装后即可启动。

![技术栈](https://img.shields.io/badge/three-0.170.0-blue) ![构建](https://img.shields.io/badge/vite-5.4.x-purple)

## 功能一览

**产品展示**
- 68 键 65% 紧凑配列（五行）：字母区、数字行（含上档字符小字）、方向键、PgUp/PgDn/Home/End 编辑列，以及 6.25u 空格、2.25u/1.75u Shift、2.25u 回车等不同宽度大键
- 键帽为带锥度 + 中心凹弧的立体几何，有高度、有间隙、字符可读（Canvas 纹理绘制，随主题重绘）
- 底壳有厚度（含边框围栏、内托盘、前后支脚）与约 5° 打字倾角；定位板 + 轴体（下壳 + 彩色轴心）独立成层
- 首屏即呈现产品名、简介、完整 3D 键盘与主要配置控件；开场自带「组装」入场动画

**交互**
- 3D 视角：拖拽旋转、滚轮 / 双指缩放、「复位视角」一键回到默认机位（带平滑飞行）
- 三种外壳配色 × 三种键帽主题任意组合，3D 预览、强调色（页面点缀色）与配置摘要同步变化
- 「拆解视图」：键帽 / 定位板+轴体 / 底壳三层平滑展开与复原（逐行错峰动画），快速反复点击后仍精确收敛到正确位置
- 「键入体验」：开启后敲击 A–Z / 空格等实体按键，对应键帽下压并回弹，伴随合成按键音；触屏 / 鼠标点击键帽同样可试轴
- 焦点在输入控件时不劫持输入：页面提供演示输入框，在其中打字 3D 键盘不会响应
- 配置（外壳 / 键帽 / 拆解状态 / 键入体验 / 按键音）自动保存到 `localStorage`，刷新后恢复；「恢复默认」只清除此页面自己写入的配置键，不碰其它数据

## 快速开始

```bash
npm install
npm run dev        # 开发模式，默认 http://127.0.0.1:5173
```

构建与预览产物：

```bash
npm run build      # 产物输出到 dist/（base='./'，可直接静态托管）
npm run preview    # 本地预览构建产物
```

环境要求：Node.js 18+（实际验证环境：Node 24.16.0 / npm 11.13.0）。无任何外部 CDN、字体或 API 依赖，可离线运行。

| 操作 | 方式 |

| 旋转 / 缩放 / 复位 | 左键拖拽 / 滚轮或双指捏合 / 右上角「⌖ 复位视角」 |

## 实现说明

- **模型组织**：键盘分为 `caseGroup / plateGroup / stemGroup / capsGroup` 四组；68 枚键帽为独立 Mesh（便于逐键按压动画与拾取），轴体用 `InstancedMesh` 合批。键帽几何按宽度缓存，字符纹理按「主题+键位」缓存。
- **动画策略**：拆解 / 按压 / 入场动画全部是「目标值 + 指数平滑」的状态机，任何时刻改目标（包括快速反复触发）都会平滑收敛到正确状态；逐行不同的收敛速率形成错峰波浪。
- **状态管理**：单一 `state` 对象驱动 3D、UI 与摘要；变更即持久化到 `localStorage`（键 `axis68.config.v1`），加载时校验合法性再合并默认值。
- **拾取与防劫持**：键帽点击 / 悬停走 Raycaster；键盘事件先检查 `event.target` 是否位于输入控件（`input / textarea / select / contenteditable`）内，是则完全跳过，且全页不使用 `preventDefault`，不干扰任何正常输入。
- 另附调试句柄 `window.__axis68`（指向键盘模型实例），便于在控制台检查状态。

## 验证记录（如实）

以下为本机（Windows 11，Node 24.16.0，Chrome 内嵌浏览器）实际执行并观察到的结果：

**已通过**
- `npm install`、`npm run build` 成功（产物 JS 519KB / gzip 133KB，构建两次通过，含修改后复建）。
- `npm run dev` 启动正常，页面首屏完整：产品名 / 简介 / 完整 3D 键盘 / 配置控件同屏可见，开场组装动画正常播放。
- 实测点击切换键帽主题（霜白→墨玉）与外壳（石墨黑→月岩银）：3D 材质、页面强调色、配置摘要同步更新；键帽字符经放大截图确认清晰可读。
- 「拆解视图」展开 / 复原动画经截图确认三层结构清晰；程序化快速反复切换 6 次后读值确认精确收敛（`plateY=0`、键帽位移归零）。
- 「复位视角」实测回到默认机位。
- 配置持久化：切换配置后 `localStorage` 写入正确；页面多次意外重载（测试环境问题，见下）后均正确恢复上次配色与摘要；「恢复默认」实测后 `localStorage` 中本页键被移除（值为 `null`）、全部状态回到默认。
- 键入防劫持：焦点在输入框时派发按键事件不触发任何键帽（读值验证），焦点移开后恢复；真实键入 `hello axis68` 成功落入输入框且 3D 无响应。
- 按压回弹：以「派发真实事件 + 手动泵帧」方式数值验证——A 键与空格按下 `press→1`、位移 −0.17，松开后归零；事件监听确认能收到 `KeyboardEvent`。
- 渲染循环运行期间全程无 JS 错误（挂载 `error` / `unhandledrejection` 钩子收集，始终为空）。

**环境限制与未尽事项（如实说明）**
- 内嵌测试浏览器在窗格隐藏时会节流 `requestAnimationFrame`（标准浏览器行为），部分后段截图取到的是冻结的旧合成帧；因此「按压回弹」未拿到理想的实时截图，改用上述数值验证，结论可信。真实浏览器中窗口可见时动画正常（前段实测均已看到）。
- 测试中出现过两次页面意外重载（伴随一次自动化点击报 `target closed`），疑为该内嵌浏览器对 WebGL 页面的偶发崩溃回收，非应用代码错误（重载后无错误、状态恢复正确）；已在代码中加了 `webglcontextlost` 处理以提高健壮性。
- 按键音逻辑（开关切换、仅在用户手势后触发）已验证代码路径，但自动化环境无法实际听音，音色未做主观评价。
- 未做移动端真机触控测试；触屏点击键帽走与鼠标相同的 Pointer Events 路径，逻辑一致。
