# DeepSeek V4.1 Flash · Extra — 微缩铁路小镇

第二题的独立作品，Extra 为模型思考等级。使用[桌面微缩铁路小镇提示词](../../../tasks/miniature-railway-town/PROMPT.md)，与已有 DeepSeek V4.1 Flash 作品分别收录。

原交付为单个 HTML 文件，内含样式、场景代码与 Three.js，保留原始页面。支持视角旋转、缩放和平移，以及列车暂停、复位、车速调整和光照切换。

## 运行

可直接打开 `index.html`，或在仓库根目录运行：

```bash
npm install
npm run dev --workspace=railway-deepseek-v4.1-flash-extra
npm run build --workspace=railway-deepseek-v4.1-flash-extra
```

构建按原样复制页面到 `dist/`。`docs/cover.png` 和题目目录中的截图供画廊展示使用。
