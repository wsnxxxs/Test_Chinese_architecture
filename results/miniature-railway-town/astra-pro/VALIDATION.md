# 验证记录

本文件区分实际执行的验证、执行失败的步骤，以及尚未验证的部分，不将源码静态检查等同于浏览器运行通过。

## 已执行并通过

测试环境：Node.js `v22.16.0`、npm `10.9.2`。

### `npm test`

结果：**20 项测试，20 项通过，0 项失败**。

覆盖内容包括：

1. 闭合轨道首尾的位置与切向连续；八个线段/圆弧连接点连续。
2. 弧长采样速度一致；负距离与多圈取模正确。
3. 路径距离函数、车体与转向架姿态。
4. 全圈相邻车体屋顶包络分离，以及弯道前后车距范围。
5. 精确到站、约 2 秒停站、逐圈触发与大时间步事件处理。
6. 行驶与停站期间的暂停状态均冻结。
7. 速度倍率不改变停站时长；分帧更新的一致性。
8. 确定性逻辑复位、数值输入保护。
9. 两处铁路跨河位置、建筑檐口平面净空、站台停车对齐和道路连接布局。

这些测试使用解析轨道和布局数据，不创建 Three.js 场景，不证明全部模型的实际渲染、树冠净空、三维细节或视觉质量。

## 尚未验证

没有完成实际 Vite 页面启动、真实浏览器/WebGL 渲染或端到端交互验证。没有实际帧率、GPU 显存、性能或浏览器兼容性测试结果。未把平面布局诊断图作为沙盘运行截图交付。

在可访问依赖源的环境完成 `npm install` 后，建议进行以下人工验收；下列项目都是**待验收**，不是已通过记录：

| 待验项目 | 检查方式 |
| --- | --- |
| 开箱画面 | `npm run dev` 后，确认完整木底座、河流、两座铁路桥、车站和三节运行列车均可见，控制台没有错误 |
| 轨道与过弯 | 连续观察至少两圈；确认铁轨闭合、三节车体独立朝向、车轮贴轨、不与桥梁或建筑相碰 |
| 每圈停站 | 每次到站均停留约 2 秒，然后继续运行 |
| 暂停倒计时 | 停站中暂停，等待数秒后继续；位置和剩余停站时间应保持，而非在暂停期间到点离站 |
| 速度 | 分别测试 0.25×、1×、2×；到站仍停留约 2 个有效运行秒 |
| 昼夜 | 来回切换并等待过渡完成；检查车站、路灯、部分窗户及机车灯，夜景应仍能看清模型 |
| 确定性复位 | 修改速度、昼夜和视角后复位，多次比较初始状态；复位不应留下镜头阻尼漂移 |
| 窗口与交互 | 检查常见桌面尺寸与窄屏；缩放、旋转、键盘操作、说明对话框均无明显遮挡或异常 |
| 后台恢复 | 切换标签页后返回；列车不应补跑离开期间的时间 |
| 生产模式 | `npm run build` 后运行 `npm run preview`，再次检查资源加载和主要功能 |
| 性能 | 在目标设备上检查运行、拖动和昼夜切换时的帧率与稳定性 |
