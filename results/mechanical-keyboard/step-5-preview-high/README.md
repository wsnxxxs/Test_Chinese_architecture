# AXIA K65 · 客制化机械键盘 — 交互式 3D 产品展示与配置页

一个纯前端的产品级展示页：**Three.js** 渲染完整可交互的 3D 机械键盘，**HTML/CSS** 承载全部配置操作（不把界面画进 Canvas）。首屏同时呈现产品名称、简介、完整 3D 键盘与主要配置控件；支持配色组合、三层拆解动画、真实按键体验与本地配置持久化。

产品为原创虚构型号，未复刻任何真实品牌。

## 快速开始

```bash
npm install       # 安装依赖（three + vite）
npm run dev       # 启动开发服务器（默认 http://127.0.0.1:5199，端口被占用时自动顺延）
npm run build     # 生产构建，输出到 dist/
npm run preview   # 本地预览生产构建
```

无后端、无外部素材（键帽字符、Logo、按键音全部在运行时程序化生成），克隆后安装即可直接启动。

## 功能一览

**3D 模型（程序化参数化建模，无外部模型文件）**
- 67 键紧凑布局：完整数字行、字母区、两个不同宽度 Shift（2.25/2.75u）、2.25u 回车、6.25u 空格、四方向键、右侧 Del/Home/PgUp/PgDn 导航列
- 键帽：OEM 式顶部收紧轮廓 + 顶部圆角、1.2mm 间隙、双色注塑字符（符号在上、主字符在下，如 `1` 上方带 `!`）
- 可辨认的三层结构：**键帽**（独立网格 + 字符贴片）→ **定位板**（1.5mm 开槽钢板 + Gasket 硅胶垫，63+ 个轴体开孔）→ **底壳**（5mm 底板 + 3.5mm 四围边框 + 5.5° 倾角），另有 PCB、电池、USB-C 口、橡胶脚垫、前壳丝印
- 摄影棚光照：环境反射（RoomEnvironment IBL）+ 主光/补光/轮廓光 + 软阴影 + ACES 色调映射

**配置与交互**
- 3 种外壳配色（云雾白 / 石墨灰 / 松林绿）× 3 种键帽主题（曜石黑 / 奶醇白 / 加州橙强调键）任意组合，3D 预览与配置摘要实时同步
- 「拆解 / 组装」：键帽层、定位板层、底壳层平滑展开与复原；指数趋近插值，快速反复点击也只会收敛到最终状态
- 「体验模式」：实际按下 A—Z 或空格，对应键帽下压回弹（带按压提亮）；也可直接点击 / 触屏点按 3D 键帽；实时显示输入轨道与敲击次数
- 输入框获得焦点时完全放行按键，不劫持正常输入（面板内提供「试试输入」演示）
- 整体旋转（拖拽）、缩放（滚轮 / 双指）、复位视角（按钮或双击，带补间）、初始入场动画
- 可选的合成按键音（WebAudio，无音频文件，默认关闭）
- 配置自动保存到 `localStorage`（命名空间 `axia.k65.config.v1`），刷新后恢复配色、拆解状态等；「恢复默认」只清除本页自己的键，不影响其它应用数据

## 使用方式

- **查看产品**：拖拽旋转、滚轮缩放、双击或点「复位视角」回到初始机位
- **换配色**：点击右侧面板或舞台工具条的色板 / 开关，3D 模型与摘要同步更新
- **看结构**：点「拆解视图」，三层分离；再点一次复原
- **试手感**：开启「体验模式」后直接敲键盘（A—Z / 空格），或点击画面中的键帽
- **保存 / 重置**：配置自动保存；「恢复默认」仅重置本页配置

## 实现说明

- 模型单位 1 = 1mm；整机以定位板顶面为 y=0 基准向上堆叠（轴体 11.1mm → 键帽 9.8mm），整组绕 X 轴倾斜 5.5°
- 键帽按宽度分 8 类用 `InstancedMesh` 渲染（单次DrawCall/类），实例颜色随主题、按压、悬停变化；字符与定位板开孔均为运行时生成的几何/贴图
- 拆解与按压动画均采用「指数趋近目标值」插值（`x += (target-x) * (1-exp(-dt·k))`），与帧率无关，反复交互不会丢状态
- `three` 的 `ExtrudeGeometry` 倒角会向 `depth` 两端各延伸一个 `bevelThickness`，`geom.js` 的 `extrudeY()` 已按最终总高度做补偿
